# 決定ログ

決まったこと、決めた日、理由を残す。覆したときは、消さずに新しい行で「変更」と書く。日付は 2026-10-13（企画の設計セッション）。

## 企画の方針

| 決定 | 理由 |
|---|---|
| エンジンは name-name。見た目と内容だけを差し替える | 新しいエンジンを作らず、汎用機能として育てる。他のゲームでも使える |
| 背景は実写、物は実写の切り抜き、人物は生成画像 | 人物は肖像権のため生成にする。物は実際に撮ることで現実ファンタジーの味が出る |
| 人物は必ずイラスト調で生成する | 実写寄りに生成すると、実在の人物に見える（戦闘画面イメージの v1 で確認、v2 で解消） |
| すべてをアクスタ風に統一する。見た目は、立ち絵の周りに白い余白を塗る代わりに、透明な余白を取って枠線を引く。台座と影は新規 | 実写背景でも境界が読めるようにする。作品の独自性にもなる。ノベル側の紙人形輪郭（白い余白）に近い形式なので、仕組みを再利用できる |
| アクスタ処理は描画時にかける（焼き込まない） | 素材を撮り直さずに、見た目を調整できる |
| 実写素材の撮影は当面できない。生成画像で仮置きし、パス指定で後から差し替える | 試作を止めない |
| リポは公開。実写素材は個人情報を処理してからコミット | 公開リポのため |
| リポ名と題名は `sit-by-me` / Sit by Me | 有名作の題名をそのまま使わず、一字ひねって作品固有にする。「stand」を「sit」に替え、車椅子の人の隣に座る動作に結びつく。題の商標確認は公開前に行う |

## 物語

| 決定 | 理由 |
|---|---|
| 主人公は男女から選ぶ。必ず車椅子の側。相手は立てる側の異性の幼馴染 | 立場の違いを物語の核にする。選ぶのは性別だけで、脚本は二人分で済む |
| 冒頭は幼稚園の劇。立てる4人が段ボールのドラゴンと戦う | FF9（劇）と FF2（いきなり戦闘）のオマージュ。のちの劇の再来の伏線 |
| 事故は劇のあと、川や海などの自然の中で起きる。かばった側が車椅子になる | 誰の責任でもない事故にする。善意でかばった人が被害に遭う水難の現実と重なり、警鐘になる |
| 事故の場面は再現せず、暗転する | 再現するほど重くなりすぎる |
| 事故は、水辺で、水の召喚獣（日本古来の神や妖怪のような存在）に襲われる形にする。普通に溺れかけたのではない（当初案の「急な増水・離岸流」を変更） | 水辺に近づいたせいで神や妖怪に襲われる、という民間伝承は、古来の水難への警鐘そのもの。召喚獣の要素にも結びつく。誰の責任でもない事故という条件は保つ |
| 主題は、謝罪にも脅迫にも見えないほどの愛 | 告白する側がどちらでも、謝罪か脅迫に見えてしまう構造への解答 |
| 再会した友達に一度惹かれた上で、幼馴染を選ぶ | 他の選択肢があった上で選ぶことで、愛が選んだものになる |
| 結婚相手は当面、幼馴染の一択。将来 DQ5 式に複数候補にする | まず作る範囲を絞る。拡張に備えて「相手」スロットで持つ |
| プロポーズは「君の隣に座らせて」の意味の英語（案: Let me sit by you.）。時期は、トクリュウとの対決のあと、壮年編が始まるまでの間 | 題名への応答。対決（中盤）のあとに恋愛の決着を置く |
| 友達2人は男女。1人は少年編で引っ越し、青年編で再会する | パーティの人数が 4→3→2→4 と変わり、劇の4人が青年編で再びそろう |
| 闇落ちするのは主人公と同性の友達。きっかけは家庭の貧困、トクリュウの受け子、少年院 | FF2 のレオンハルト、FF4 のカインのオマージュ。現実の社会問題として描く |
| ヒロインが友達に献身的になり、主人公が嫉妬し、成長する | 同情と愛の違いという主題に直結する |
| 少年院や警察署を襲撃しない。本部は外国で、資金を貯めて向かう | 更生の場を侮辱しない。公的機関が別ルートで動いていることも描く |
| トクリュウは竜の当て字の仮想的なモンスターの組織 | FF6 の八竜にかけ、劇の再来にする |
| **雰囲気は MOTHER2 の日本版のようなもので、ダーク**。日本風の葬式や火葬場も描く | 現代日本の日常を、子供の視点で、少し不思議でダークに描く。明るいアクスタの見た目と、重い題材の落差が味になる。葬送の描写は、正確さと遺族への配慮のため、確認を受ける |
| **世界は二層**。見た目は「少し不思議な現実」だが、実際はリアルな現実。召喚獣は実在せず、主人公が想像で作った像。納得のいかないとき、想像で妖怪や神のせいにして心を守っている。思い込みによる像か現実かは、あえて曖昧に書く（『うみねこのなく頃に』に近い） | 主人公はイマジナリーフレンドを作れるほど想像力が豊か。作品の主題（避けられない悲劇への心の持ち方の練習）の一つの形になる。事故（水の召喚獣／自然の水難）、配偶者の召喚獣（心の中の存在）、運命（病気）を、表と裏の二層で読める |
| 外国は実在の国名を出さない | 実在の国や地域への誤解を避ける |
| トクリュウのアジトは東南アジア（地域として示し、実在の国名は出さない）。飛空艇は、普通の旅客機で、アジトへ行くときに乗る | 現実ファンタジーの方針（FF の飛空艇を、現実の乗り物に言い替える）。地域や人々への偏見を避ける配慮をしつつ、舞台を具体的にする |
| **トクリュウとの対決は中盤**。最後は壮年編で、運命が敵になる（当初の「終盤にトクリュウ本部を襲撃する」を変更） | 物語の終盤を、人生の終わりに向かう壮年編にする |
| 壮年編: 子供3人（主人公と配偶者の子）が仲間になり、友達2人が離れる。配偶者が病気で亡くなり、召喚獣となって会える。主人公＋子供3人の4人パーティ。配偶者の死は「そうなる運命だった」と納得しかできない形で、運命が敵になる | 子育て、世代、喪失を、召喚獣と運命で一つにつなぐ。主人公は生涯固定のまま（世代交代はしない） |
| **作品の主題は、人生を疑似体験し、避けられない悲劇への心の持ち方を練習すること**。壮年編はその最後の練習 | 事故、友達の闇落ち、配偶者の死を、避けようのない出来事として描き、遊びながら心の持ち方を練習する。運命との決着は、力で倒すのではなく、心の持ち方の表現にする案 |
| **老年編は作らない**。壮年編のあとはエンディングで、主人公が寿命を迎え、亡き配偶者に会える場面で終わる | 悲劇への心の持ち方の練習のあと、最期に再会で終える。老年を描かずに、人生の終わりを一場面にまとめる |
| エンディング時点では、同性の仲間もすでに亡くなっていて、異性の仲間1人だけが主人公を見送る側になる | 青年編で一度惹かれた友達が最後に見送る。人生の終わりに残る人を一人にして、喪失と見送りを描く |

| 再会する友達は就職していて、その職業が奪還の役に立つ | 職業システムと整合させる。具体の職業は未決 |
| 描写は専門家や当事者の視点で確認する（sit-by-me#2） | 水難、障害、少年院、闇バイトを扱うため、正確さと配慮を確保する |
| **世界観は、少し未来の日本**。混血や移民が進み、服装や髪の自由度も上がった世界。登場人物は、全員を「日本人の見た目」に固定しない（髪色・肌・顔立ち・服装の幅を持たせる）。外国はトクリュウの本部の舞台としてだけ出し、実在の国名は出さない | 幼稚園の通園帽とスモック、日本の古来の神や妖怪、少年院、闇バイト、トクリュウ、受験など、物語の要素は日本が舞台。その日本が、少し未来で多様になっている。エクステ、白髪、バンダナ、開放的な服装などの特徴づけとも合う（2026-10-13 kako-jun 回答。直前の「全員日本人」の暗黙の前提を置き換え） |
| ダンジョンは友人の体内（SaGa2 のオマージュ）。魔法の世界（異世界）には行かない | 現実ファンタジーの方針。ダンジョンも現実の延長にあり、二層の世界の表の層（冒険）と裏の層（現実・想像）で読める |
| 体内に入るのは、闇落ちしたほうでなく、もう1人（異性）の友達。このキャラはエピソードが薄いので、体内ダンジョンと「みんなに助けてもらった恩」で厚くする。恩が、のちに友人を助ける動機になる。体内ダンジョンと恩のイベントは、闇落ちした友人を助ける前に必要 | 異性の友達に、青年編の再会・奪還のノウハウ・最後の見送りへつながる理由を与える。恩が奪回の動機として効くように、奪回より前に置く |

## システム

| 決定 | 理由 |
|---|---|
| 戦闘はサイドビュー | FF 系の画面。敵が左、味方が右、下にコマンドと HP |
| 戦闘は ATB 方式（FF5 風）。待機とアクティブの設定を持つ | FF5 の画面に寄せる。4人パーティの戦闘に勢いが出る |
| ウィンドウは FF 風の青。色だけをテーマにし、寸法は共通 | 好みの意匠（青地、白枠、白文字）。テーマに寸法を持たせない |
| ダメージは数字のポップアップ。被ダメージの点滅はさせない | FF 系の表現に合わせる。私の点滅の案は取り下げ |
| 武器は日用品。必殺技は武器に紐づく | 現実で可能な武器にする。例: 学生鞄の「カバンストラッシュ」 |
| ジョブは二軸。フィールドジョブ（本当の転職、主にパッシブ）と戦闘ジョブ（アクティブ）の合成 | FF5 のアビリティの移植ではなく、合成で独自性を出す |
| 組み合わせはタグ × タグの変換ルールで定義する | 全組み合わせを手書きしない。発見の楽しさは残す |
| パッシブが効いたことは画面に明示する | 暗黙の挙動を作らない |
| 仲間の職業は加入時に決まる。主人公は自由に転職できる | 人生の選択と、仲間の固定の役割を分ける |
| FF の要素は、固有名詞を使わず現実のものに言い替える | 勇者ヨシヒコ式。著作物の固有名を借りずに構造を借りる |
| 召喚獣は後で入れる。日本の古来の神や妖怪のような存在にする | 水の召喚獣の事故と物語がつながる。現実ファンタジーとも合う |
| 立ち絵は、普通に立つポーズに加えて、詠唱などは過剰なポーズ（ジョジョ立ちのように）にする | 普通のポーズだけでは、技や状態の差が出ない |
| マスター画像を先に作り、ポーズ一式はタイル状の1枚にまとめて生成する | 同時に作ったほうが同一性を保てる |
| いまのキャラ画像は仮のテンプレ絵。後で差し替える。差し替えるときは、キャラごとの特徴（エクステで髪の一部が別の色、眼鏡、カラフルなバンダナ、開放的な服装、三白眼、白髪など）を入れる | テンプレ感（AI くささ）を消して、キャラを際立たせる |
