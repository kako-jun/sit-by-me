# シナリオ・自動イベント台帳

時代は `ERA`、場面は `E` で管理する。会話、歩行開始／終了、マップ遷移、戦闘開始・終了、仲間の出入り、カメラ演出、条件付き通行、強制ワープ、アイテム・魔法・アビリティの付与は、すべてイベントとして1行にする。台詞本文や演出の詳細は各 `E` の詳細節または `story.md` に置くが、ここから参照できなければ実装しない。

各イベントの必須項目: ID、ERA、状態、開始条件、MAP、参加者（C）、敵／ボス（M/S）、取得物（L/B/I）、遷移先E、TBD。TBDが1件でもあれば `blocked` であり、自動実行・実装・画像生成をしない。
