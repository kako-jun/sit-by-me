# ボスのギミック台帳（案の一覧）

作成: 2026-10-15（kako-jun 指示「ギミックは思いつくたびに入れたい。案は一覧しておいてくれ」）。

- **運用**: ギミックを思いついたら、ここに追記する（ID・内容・出典・実現可否・使う予定のボス）。**採否と割り当ては kako-jun が決める**。採った分だけ `docs/monsters.md` の「役割」「弱点・耐性」、`docs/enemy-allocation.md` §5（個性表）へ反映する。
- **方針**（decisions.md 2026-10-15）: ボスはどれも個性豊かにする。FF5 の次元城のように、得意攻撃・属性・戦い方をばらす。ラストダンジョンのボスラッシュは、これまでの集大成。**戦闘に特殊なコマンドは入れない**（FF らしくない）。ギミックは、敵の専用 `[特技]`、行動パターン（P0〜P3）、状態異常、属性・耐性で表す。
- **実現可否**は、name-name の敵 AI の実装（`docs/design/enemy-ai.md` §2.2・§3.9）で確認した事実。「できる」＝既存機能で書ける、「擬似」＝別の機能で近い体験が作れる、「要実装」＝エンジンに足す。
- 要実装の土台: **状態異常システム（name-name #870）**、形態変化・仲間への反応（P4。未起票）。

## 2. 召喚獣の中ボスの個性づけ（私の案。採否は kako-jun が決める）

召喚獣系の中ボスは、属性の弱点とカウンターしか差を付けにくい（kako-jun の所見）。既存機能（反撃・周期・予兆）だけで、戦い方に差をつける案:

| ボス | 案 | 使うギミック |
|---|---|---|
| 氷の召喚獣 S002（凍った森） | 周期で「凍る」予兆を出し、放置すると全体に大ダメージ。時間制限型 | G009 |
| 風の召喚獣 S003 | 魔法を受けると同じ系統で返す、リフレク的な反撃 | G003 |
| 火の召喚獣 S004（ネコ型・会話できる） | 殴るほど怒って反撃が強くなる、被弾連動型 | G008 |
| 水の召喚獣 S001 | （負けイベントのため通常の個性づけは別）心臓の戦い（体内）で、別の戦い方を検討 | G015 ほか |
| 土の召喚獣 S005 | 時間制限の脱出戦。壊れる足場など | G013 |
| 雷（M004・M005） | ラスボス。多部位戦・形態変化 | G011・G012 |

## 3. 属性・状態異常の空き（事実。docs/enemy-allocation.md §5 から）

- 属性は、6属性を召喚獣系のボスが1つずつ使っている。召喚獣以外のボスは、属性がすべて未定。
- 状態異常で記録にあるのは、匿龍の毒・混乱だけ。ゾンビ（G005）は、`docs/systems.md` で「属性・魔法・召喚獣のカテゴリに入れない」とされているので、**属性ではなく状態**として扱う。
