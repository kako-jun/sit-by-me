# ボスのギミック台帳（案の一覧）

作成: 2026-10-15（kako-jun 指示「ギミックは思いつくたびに入れたい。案は一覧しておいてくれ」）。

- **運用**: ギミックを思いついたら、ここに追記する（ID・内容・出典・実現可否・使う予定のボス）。**採否と割り当ては kako-jun が決める**。採った分だけ `docs/monsters.md` の「役割」「弱点・耐性」、`docs/enemy-allocation.md` §5（個性表）へ反映する。
- **雑魚にも適用**（kako-jun 2026-10-15: 雑魚戦の難度も高めにする。FF13 参照。単調な消化にしない）。§5 のパターン（反撃・周期・予兆・状態異常など）は雑魚にも使う。
- **方針**（decisions.md 2026-10-15）: ボスはどれも個性豊かにする。FF5 の次元城のように、得意攻撃・属性・戦い方をばらす。ラストダンジョンのボスラッシュは、これまでの集大成。**戦闘に特殊なコマンドは入れない**（FF らしくない）。ギミックは、敵の専用 `[特技]`、行動パターン（P0〜P3）、状態異常、属性・耐性で表す。
- **実現可否**は、name-name の敵 AI の実装（`docs/design/enemy-ai.md` §2.2・§3.9）で確認した事実。「できる」＝既存機能で書ける、「擬似」＝別の機能で近い体験が作れる、「要実装」＝エンジンに足す。
- 関連: **ラーニングできる魔法の順番・時期の配置**も大事（kako-jun 2026-10-15）。`docs/learning-schedule.md` に表を置く。
- 要実装の土台: **状態異常システム（name-name #870）**、形態変化・仲間への反応（P4。未起票）。

## 3. 属性・状態異常の空き（事実。docs/enemy-allocation.md §5 から）

- 属性は、6属性を召喚獣系のボスが1つずつ使っている。召喚獣以外のボスは、属性がすべて未定。
- 状態異常で記録にあるのは、匿龍の毒・混乱。ほかにボスギミック案として G023〜G025（ゾンビ相当の状態・死のルーレット・死の宣告）がある（いずれも案・未決）。ゾンビ（G005）は、`docs/systems.md` で「属性・魔法・召喚獣のカテゴリに入れない」（基本完成までの一時措置。2026-10-20、decisions.md 287行参照）とされているので、**属性ではなく状態**として扱う。

### 5.0 推理バトル（G017）の作り方メモ（案）

- **トリガーの種類**（既存機能で書けるもの）: 受けた攻撃の種類（物理／魔法／特定の属性）、被弾の回数、行動の周期、自分や相手の状態、HP 割合、使った技の回数。
- **ヒントの出し方**: 予兆の文言（「目が光った」など）、行動ログ、敵の台詞、戦闘前の会話。**間違った攻撃をしたときの反応**がそのままヒントになる（P002 魔法を返す・P003 殴ると怒る・P011 近づくほど固い・P020 物理に居合）。
- **ずる（総当たり）対策**: トリガーが1つだけだと総当たりで解けてしまうので、(a) 間違いにペナルティ（反撃）を付ける、(b) 複数の勝ち筋（systems.md・#15）を置く、(c) 予兆が毎回少し違う、などを併用する。
- **トリガーを満たす道具**（G018）: 推理の答えを実行できる手段（偶数固定の「ハリセンボン」、奇数固定の道具、属性を揃えた攻撃など）を、**答えが分かった後に使える形で用意**する。道具の入手（ドロップ・ぬすむ・戦利品。台帳 3-6）とのつながりを決める。（ぬすむはオトン・ナムの 2 人まで使える。kako-jun 2026-10-15。関連 #831。ぬすむの刀を持つ間は他のアビリティが使えない）
- **ダメージの奇数／偶数トリガー**（#871）: 乱数の幅があるとプレイヤーが狙えない。偶数固定の道具があれば「分かったら使える」になり、推理がゲームとして成立する。
- 同じトリガーの型を他のボスで使い回さない（個性表 §5 のかぶり確認）。
