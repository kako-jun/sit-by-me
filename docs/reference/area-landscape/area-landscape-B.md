調査日 2026-11-02。リポ資料は `origin/main` を読み取り専用で展開して参照（変更なし）。
Web は WebSearch／WebFetch で本文確認できた事実のみ「事実」に入れた。信頼度: 高=公的／百科、中=観光・撮影ガイド・個人記録、低=推測を含む。
**重要な総評**: 公開 Web で取れた「冬の実景」は薄い（4エリアとも、積雪時の写真描写や学校自体の細部は確認できず）。このため各章の 4. は「実景の特徴（確認済み）＋冬の仮想」で構成し、**仮想**と明記した。

共通の前提（リポ資料より）:
- 背景は実景の再現でなく「その場所のイメージ」のジオラマ（art-direction.md）。ランドマークだけは一目で分かる程度に寄せる。
- 素材語彙: 雪=綿、木=スポンジ／ドライフラワー／毛糸塊、建物=厚紙・段ボール・紙粘土、塀=紙粘土・発泡スチロール、道路=黒画用紙・紙やすり／市街地はグレーの砂、電柱=割り箸、水=セロファン・透明レジン。
- 全編冬・暗い曇天・積雪・融雪水・雪で傷んだ道。奥行きを出さない真上寄りの見下ろし。
- 雪国共通語彙: 消雪パイプ、赤白スノーポール、雪囲い、雁木、除雪の雪山、融雪水、錆びたトタン、黒ずんだ木壁。
- エリア固定の木: mountain=杉+枯木、school=山の木（樹種を特定しない）、uchinada=クロマツ+アカシア（外周は綿の雪に淡黄の砂）、airport=松。

# 1. mountain（卯辰山の一本道, UTS-01〜05）

## 1. 一言で言い当てる実体の特徴
**「浅野川の東岸、寺と坂と階段が迷路のように重なる斜面を、杉・桜・竹の木立と展望台へ折れ曲がりながら登る城下町裏手の小さな里山」**。
山そのものは標高141mの低い山で、金沢城を見下ろす位置にあり、頂上近くから金沢の市街・河北潟・日本海が見える。「登るほど街が下に広がる」ことが決め手。

## 3. 冬の姿
確認できた範囲: 雪化粧、路面凍結、冬晴れの遠景（日本海・白山）。積雪量や杉の雪の付き方、山道の除雪実態は**確認できなかった**。
北陸の冬一般: 寒波の年は降雪量がかなり多く、暖冬の年は少ない（年差が大きい）。12月は冬型が続きやすく日照が少ない傾向（気象庁新潟地方気象台の冬のまとめ。https://www.data.jma.go.jp/niigata/menu/kisetsu/2021winter.pdf、https://www.data.jma.go.jp/niigata/menu/kisetsu/2025winter.pdf）。信頼度 高（ただし金沢の卯辰山固有の数値は未確認）。

## 4. 冬の景色の仮想表現（MAP の見た目の指定に使える描写案）
全体: 低い里山。雪の綿は薄めで、道の中央は人の通り道として土の茶と濡れた石が見える。杉は暗緑、広葉の枯木は茶の枝に綿を点付け。竹は少数の細い棒に雪の重みで曲がる形（仮想）。

- 共通の材料案（仮想）: 登山道＝茶色の厚紙＋灰色の砂（踏み固めた雪解けの濡れ道）、階段＝段ボールを重ねた段、石垣＝灰色紙粘土の積み、杉＝スポンジの縦長円錐に暗緑、枯木＝針金に毛糸、手すり＝割り箸、雪＝綿を風下側に厚く。
- 道の幅は車椅子で押せる幅を保ち、階段は景観の脇（リポ決定どおり）。

## 5. MAP と使える特徴
- **UTS-01（浅野川橋の先で杉林へ折れる寺門の登り口）**: 実景特徴＝浅野川に隣接する麓、坂と長い階段、小路、寺社。事実の使い方: 川沿いの平場→橋→麓の寺の石段・小路。仮想: 橋は低い木桁、欄干に雪、寺門は小さな屋根つきで雪の庇、門脇に石灯籠に綿の帽子、小路は左右の寺塀の隙間（土塀の寺町と同じにしない。山麓は石段と生垣・低い石積みを混ぜる）、杉の根元だけ雪が薄く濡れた石と落ち葉と泥。
- **UTS-02（廃遊具の脇を二度折り返す山腹道）**: 実景特徴＝整備された小道、階段、ベンチ、竹林。廃遊具はゲーム内設定（実景なし）。仮想: ベンチは雪の座面、竹林の細い葉が雪で垂れる、錆びたジャングルジムを雪が半分埋める。
- **UTS-03（雪をかぶった展望東屋を回り込む尾根道）**: 実景特徴＝展望台（望湖台・見晴らし台）から市街・日本海。東屋の有無は実景で未確認（個人記録に東屋の記述なし）。仮想: 四角い屋根の東屋に厚い雪、手すり柵に雪、尾根は左右が落ちて遠景の街と海の灰色帯が見える。
- **UTS-04（崩れた石垣を避けるヘアピン坂）**: 実景には崩れた石垣の確認なし（ゲーム設定）。山麓の石積みの雰囲気（坂・階段・石積み）を転用。仮想: 苔と雪の混じった石積みが一部崩れて土と根が見え、柵で黒マスク、主坂は踏み固めた雪。
- **UTS-05（氷の召喚獣と対峙する風穴のある山頂広場）**: 実景特徴＝山頂付近に広場と展望、三社・標識。風穴は実景で確認できず（ゲーム設定）。仮想: 凍った広場、雪を被った標識、岩肌に口を開ける小さな風穴、氷の柱。

## 6. 確認できなかったこと

- 積雪時の登山道の実景、山頂広場・風穴の実在。
- 東屋・廃遊具・崩れた石垣の実在（ゲームの設定として扱う）。

## 4. 冬の景色の仮想表現（すべて仮想: 一般的な北陸の小学校像）

# 3. uchinada（内灘・内灘線, UCH-01〜05）

## 1. 一言で言い当てる実体の特徴
**「日本海と河北潟のあいだに延びる細長い砂丘に、防砂のクロマツとニセアカシアの林が帯状に張りつき、頂の風車に冬の西風が当たる町」**。

## 4. 冬の景色の仮想表現
- 内灘線（架空）: 結露窓、赤い座席（MAP名の指定）。実在の北鉄浅野川線の車両は模写しない。
- 小駅（仮想）: 低い平屋の駅舎、板張りのホーム、風除けの柵、風で斜めに積もった綿の雪。留置線は錆びたレールと砂混じりの雪。
- 防砂林（実景＋仮想）: クロマツは濃緑の房を風下側へ傾け、根元に砂混じりの汚れた雪。アカシアは葉の落ちた細い枝（枯れた木）に綿。
- 木道（仮想。実景で木道は確認できず）: 濡れた板、海風で錆びた柵、板の隙間に砂。
- 砂丘頂（実景＋仮想）: 風車柵は低い木の柵に雪の吹き溜まり、遠景に風車（白い3枚羽根）、海は画面上に灰青の荒波と白い波頭。
- 砂浜（実景＋仮想）: 淡黄の砂に薄い雪がまだらに残り、風紋の筋は風上から吹き寄せた雪で白く強調、波打ち際に流木。

## 5. MAP と使える特徴
- **UCH-01（結露窓と赤い座席が続く車内）**: 内灘線の車内（仮想）。窓外に灰色の砂丘と松のシルエット。
- **UCH-02（風を受ける小駅と留置線）**: 風に傾く松、雪が横に積もる、風除け柵。
- **UCH-03（クロマツ防砂林を蛇行して登る木道）**: クロマツ＋アカシア、砂丘の起伏、河北潟側が急で日本海側が緩い断面。
- **UCH-04（海を見下ろす砂丘頂の風車柵）**: 風車（65m級の白い風車）、海は上、頂から河北潟側は急斜面。
- **UCH-05（風紋と波打ち際が上側に広がる砂浜）**: 風紋、足跡、貝殻、荒波、幅広の浜（水際まで約200m）。シロチドリは冬は不在（出さない）。

## 6. 確認できなかったこと
- 砂丘上の冬の積雪実景、木道の実在、防砂林のクロマツとアカシアの配置・樹高。
- 内灘駅・浅野川線の車両の細部（架空の内灘線のため模写しない）。

# 4. airport（K空港, APT-01〜02）

## 1. 一言で言い当てる実体の特徴
**「砂丘帯の平地に、横に長いターミナルと広大な滑走路が海側から山側に向かって並ぶ、防衛省管理の滑走路を共用する空港。背後に白山の雪の稜線」**。小松空港がモデル。

## 3. 冬の姿
確認できた: 白山の雪稜線、除雪車と舞う雪、冷たい強風。ターミナル前や駐車場の雪囲いの実景は確認できなかった。

## 4. 冬の景色の仮想表現
- 外（APT-01、仮想）: 横に長い低い2〜3階建ての白灰色の箱、ガラスの庇。送迎車線は黒い路面に除雪の雪山が両側、赤白スノーポール。「雪囲い」＝縄と竹／板で囲った植栽（松）。
- 松（ユーザー決定＋仮想）: 前面の植え込みに黒松（クロマツ）数本、雪囲いの藁縄で支え、枝に綿。砂丘帯に立つ空港という事実に沿わせると、松は海風を受けて少し傾く。
- 低い管制塔（MAP名の指定）: 白い低塔、頂部のガラス窓に雪。管制は自衛隊と共用という事実があるため軍事的な記号は出さない。
- 背景: 遠景に白山の雪稜線を描くかは任意（K空港の所在地を明かさない方針と矛盾しない範囲で、山は「白い稜線」程度）。駐機場は通行不能（雪の積もった飛行機の翼、除雪車）。
- 中（APT-02、仮想）: 白い蛍光灯、リノリウムの床、濡れた足跡、搭乗口の案内板。

## 5. MAP と使える特徴
- **APT-01（雪囲いの送迎車線と低い管制塔）**: 雪囲いした松、送迎車線、除雪車、白山の稜線、駐車場。展望デッキは実在する特徴だが通行不能の脇として扱う。
- **APT-02（白い蛍光灯の下で搭乗口へ折れる空港内）**: 蛍光灯、保安検査、搭乗口。実景の屋内は確認できず、一般的な空港像の仮想。

## 6. 確認できなかったこと
- 小松空港ターミナル前の松の実在と本数、ターミナルの外観、ロータリー・送迎車線の形、雪囲いの実景。
- 屋内（保安検査・搭乗口）の実景。
