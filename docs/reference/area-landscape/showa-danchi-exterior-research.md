# 昭和の県営住宅（量産型RC団地）の外観と棟の規模・配置 調査メモ

調査日: 2026-11-02。凡例: 【複数】=2つ以上の出典で一致、【単独】=1出典のみ、【算出】=出典の数値から私が割り算した値（出典に書かれていない）、【既定（要確認）】=出典なしの憶測。
注意: **石川県の昭和の県営住宅そのものの「外壁の色」「棟の寸法」「写真」は取れなかった**。数値は金沢市営緑住宅（昭和45〜53年・市営）、県営平和町団地（戸数のみ）、公団赤羽台41号棟（昭和37年）が中心。公団は公営の標準設計を土台にした（既報 `showa-danchi-research.md`）ので近縁だが同一ではない。

## 1. 階数

- 金沢市営緑住宅（市営だが金沢の昭和の量産団地として最も近い実例。**ペンキの白さは未確認**）: 昭和45〜53年度建設の耐火構造 37 棟。内訳は中層耐火 **5階建 13棟 376戸（S45〜49）**、**4階建 20棟 390戸（S45〜48）**、高層 4棟（7階・11階、S51〜53）。残り3棟（4階建、H6・H27建替）は後年。「東側と南側には４階建及び５階建の中層耐火構造住宅（36棟）が配置」。
  - https://www4.city.kanazawa.lg.jp/material/files/group/75/PLAN-ZENHAN.pdf（pdftotext で本文確認）
  - 同団地は昭和40年代後半から50年代前半の建設で、40棟1,358戸。【単独】
- 県営平和町団地（金沢）: 昭和28年度の県営1・2号棟（のち36・37号棟）は**中層RC造3階建**（「3階建36戸」）。昭和54年度に **49棟916戸**。
  - https://www.pref.ishikawa.lg.jp/kenju/jusei_pamph/documents/04_1.pdf（pdftotext で本文確認）【単独】
  - 「36・37号棟（3階建36戸）」の戸数が1棟分か2棟分かは文面から断定できない。
- 時期の傾向: 石川の昭和28年=3階建、金沢の昭和45〜49年=4階建と5階建が混在（緑住宅）。公団でも昭和30年の標準設計は4階建て北入り階段室型、昭和42年の67型は5階建て北入り階段室型。
  - https://www.ur-net.go.jp/rd_portal/pnf/ing_report_juu/hndcds000000a2i8-att/hndcds000000abfn.pdf（昭和30年「4階建て北入りの階段室型」を本文確認）、https://www.ur-net.go.jp/rd_portal/archive/lrmhph000001t9d7-att/p14-p15.pdf【複数・公団】
  - 「1960〜1970年代までに建設された団地は5階建てまで」https://ja.wikipedia.org/wiki/団地 【単独・二次資料】
- 全国の階数別の割合（統計）は見つからなかった。

## 2. 1階あたりの戸数と棟の規模

- 階段室型は「隣り合う2戸で1つの階段室を共用」。【複数】
  - https://allabout.co.jp/gm/gc/439166/ 「隣り合う2戸で1つの共用階段」「4～5階建て」「エレベーターがない」
  - UR 資料 abfn.pdf の「合う2戸で共用する階段室」
- **実例の棟（公団・昭和37年）旧赤羽台41号棟: 板状階段室型、地上5階建、建築面積374㎡、40戸**。「当団地以外の団地でも多くみられる標準的な『板状階段室型』」「全ての住戸に採光・通気が得られるように住棟を南面させ、各戸南側にバルコニーを設けた」。
  - https://www.UR-net.go.jp/aboutus/press/lrmhph000000zic3-att/ur2019_press_0719_akabanedai.pdf（本文確認）【単独】
  - 【算出】40戸÷5階＝1階8戸＝**4階段×1階2戸**。建築面積374㎡÷4階段＝約94㎡/階段。1住戸あたり約47㎡（住戸専用面積＋階段室＋バルコニー分）。
- 緑住宅の棟あたり平均【算出】: 4階建 390÷20＝**19.5戸/棟**（1階段あたり8戸なので約2〜3階段）、5階建 376÷13＝**約29戸/棟**（1階段あたり10戸なので約3階段）。県営平和町は 916÷49＝約18.7戸/棟（階数混在）。出典に棟ごとの階段数はない。
- 緑住宅の住戸専用面積は 40.1〜80.0㎡（2DK・3K・3DK・5DK）。【単独】PLAN-ZENHAN.pdf
- 住戸間口: 公団は昭和30年代の標準設計でモジュール800mm（畳短辺、「団地サイズ」）、67型で900mm。昭和45年の70型で「間口を狭めた」フロンテージセーブ型が登場（間口が狭く奥行きが広い）。数値の「メートル」は出典に直接は無い。旧公団の4〜5階建ては「ワイドスパン（間口が広い）」で壁式構造が多い。
  - abfn.pdf、https://allabout.co.jp/gm/gc/439166/【複数・公団】
  - 1住戸の間口＝約4.5〜5m、棟の桁行＝約35〜45m という値は、上の建築面積374㎡と4階段から出した**目安で出典の記述ではない（既定（要確認））**。
- 棟の長さ（桁行）・奥行き（梁間）をメートルで書いた資料は**確認できなかった**。階段室型は「奥行きが小さく、住戸の両面に窓がある」（UR向ヶ丘第一団地資料 https://www.ur-net.go.jp/west/renaissance/lrmhph000000gbsf-att/02-03.pdf）という定性的記述のみ。

## 3. 外観

- 白さ・外壁の色・仕上げ（打ち放し/吹付けタイル/塗装）・雨だれ: **昭和の県営住宅については確認できなかった**。わずかな周辺情報:
  - 平和町団地は昭和57年から「バルコニーをサッシュで囲いサンルーム化」、昭和63年に「団地のメイン道路沿いの外壁明装や屋根並の連続性に考慮した景観改善」を実施。つまり**元のバルコニーは吹き放し**で、外壁は後年に塗り直す対象だった。【単独】04_1.pdf
  - 緑住宅は魅力アップ策として「外壁の改善」を挙げる（外壁が古びていた示唆）。【単独】PLAN-ZENHAN.pdf
  - 大面積のコンクリート壁は雨だれ等の汚れが目立ちやすい（埼玉県、令和6年の補修指針の記述。昭和の石川の話ではない）。https://www.pref.saitama.lg.jp/documents/265221/r6senmonkaadobaisu.pdf【単独・参考】
- バルコニー: 階段室型は南北両面にバルコニー（allabout 432073 は既報。439166 も「南面と北面の2面が開放」）【複数】。41号棟は各戸南側にバルコニー。手すりの材質（鉄/コンクリ）は**確認できなかった**。
- 階段室: 階段は屋外に出ている型（芦屋の旧市営宮塚町住宅の階段室型の記述。日華石の石造外壁の例で、団地の標準ではない）https://www.city.ashiya.lg.jp/gakushuu/bunkazai/documents/miyazukasyashin.pdf【単独・参考】。階段室の縦長連窓は**確認できなかった**。
- 1階の玄関高さ: 緑住宅の階段室型棟は「１階の住戸であっても玄関は４段程度階段を上ったところにある」。**1階が地面より約4段（約0.7m前後）高い**のは実在の根拠あり。PLAN-ZENHAN.pdf【単独】
- 屋根: 昭和の県営・市営RC棟の屋根形状を述べた資料は**確認できなかった**。参考として、石川県の川辺団地（旧「一針」）は平成6〜10年度の建替で「緩やかな勾配屋根をかけた」RC造3・4階建6棟に（https://www.pref.ishikawa.lg.jp/kenju/jusei_pamph/documents/06_1.pdf 本文確認）、公団の向ヶ丘第一団地では中層住棟の勾配屋根は再生・景観の要素として扱われる。勾配屋根が平成の建替の特徴として書かれていることから、昭和の原型は陸屋根だった可能性があるが、これは**推測**。
- 棟名表示: 金沢の県営住宅は「○号棟」で呼ぶ（平和町団地「36・37号棟」「40号棟」「13号棟」）。新神田県営住宅（昭和54〜55年）は9棟に樹木名（椿・栗・柿・松・梅・楓・杏・榎・栂）を付け、壁面に自筆の棟名が書かれている。https://note.com/makiko03112002/n/n3c5f4ca0f3b0 【単独・後期の特殊例】
- 掲示板・集合郵便受け・案内板は、石川県の現行設計マニュアルが共用玄関に設置とするが、昭和の実態の記述ではない。https://www.pref.ishikawa.lg.jp/kenju/documents/fukkoukouei_manyuaru.pdf（令和7年）
- ガスメーター・玄関前の生活の跡・雨樋・配管・煙突: **確認できなかった**。

## 4. 配置と中庭

- 公団の昭和30年代の「団地設計要領」: **冬至4時間日照と住戸のプライバシー確保のため、棟間は建物高さの1.8倍（テラスハウスは2.5倍）**。板状中層の階段室型を地形に合わせて配置。幼児公園（プレイロット）を100m圏域ごとに設置。北入りと南入りを組み合わせるNSペア配置。
  - https://www.ur-net.go.jp/rd_portal/pnf/danchi100/lrmhph000000k1ma-att/danchi100.pdf（本文確認）【単独・公団】
  - 【算出】4階建（1階高さ約2.7mとして高さ約11m）なら棟間は約20m、5階建（約14m）なら約25m。階高は出典に無く既定（要確認）。
- 金岡団地（昭和31年、公団）: 板状と星形の中層住棟。ランドマークとなる樹木、外周部の桜並木、歩行者路沿いの遊び場。同 danchi100.pdf【単独】。「ひとつの広い敷地にゆったりとした間隔で数棟配置」allabout 439166【単独】。
- 南面平行配置の実例: 公団の志賀団地（名古屋）は「敷地中央にオープンスペースを有し、南面4階建て廊下型中層住棟12棟」。**片廊下型（廊下型）が中層で採用された実例**（階段室型でない）。https://www.ur-net.go.jp/rd_portal/archive/lrmhph000001t9d7-att/p40-p41.pdf（本文確認）【単独】。
- 金沢の実例: 緑住宅は東側と南側に中層、西側に高層。「入居者が協働して管理している緑地や通路などのスペースも広大」「フレンドリーパークなどの緑地」「集会所」。駐車場は1,358戸に1,248区画（昭和当時の台数ではない）。団地内に**公衆浴場**を設け、住戸内は浴槽の設置スペースのみ（H3年8月に廃業）。PLAN-ZENHAN.pdf【単独】
- 平和町団地: 犀川左岸の寺町台地、団地横に市民病院、バスの便が良い。昭和28年に3階建から。後年に集会所（H11、RC造2階建464㎡）。04_1.pdf【単独】
- 新神田県営住宅（昭和54〜55年）: 棟の角度が平行でない、各棟の高さ・幅・バルコニーが違う、集会所の隣は棟に囲まれた中庭。note.com 上記【単独、昭和末期の個性的な例】。
- 中庭に置かれる物（物干し、自転車置場、ごみ置場、樹木の種類）は昭和の県営住宅については**確認できなかった**。

## 5. 雪国の特徴

- 昭和の金沢の団地の雪対策（屋根の形、階段室、除雪）を述べた資料は**確認できなかった**。
- 参考（現行基準）: 石川県の設計マニュアル（令和7年）は「勾配屋根の場合、落雪スペースを確保」「落雪対策の庇」「風雨雪の吹き込み防止に配慮」。陸屋根（アスファルト防水・シート防水）と勾配屋根の両方を許容。https://www.pref.ishikawa.lg.jp/kenju/documents/fukkoukouei_manyuaru.pdf【単独・現行】
- 石川県の豪雪地向け木造住宅に防風・防雪スクリーン（玄関前）、雁木、載雪屋根の例（昭和RC団地ではない）。https://www.pref.ishikawa.lg.jp/kenju/jusei_pamph/documents/08_1.pdf（防風・防雪スクリーンの語のみ本文確認）【単独・参考】
- 金沢の大雪: 2018年2月の最深積雪68cm（平成で2番目）。https://www.hrr.mlit.go.jp/kanazawa/mb5_kouhou/press/saigai/180204_ooyuki/180204yuki_8-1.pdf（検索要約のみ、本文未読）

| 項目 | 案 | 根拠 / 区分 |
|---|---|---|
| 構造・型 | RC造、板状（直方体）の階段室型。ただし「入口が廊下に面する」設定は片廊下型にも対応可 | 階段室型が基本【複数】。廊下型の中層実例は志賀団地（公団）p40-p41【単独】。県営がどちらかは**確認不可**。片廊下型にするなら既定（要確認） |
| 階数 | **4階建**（A・B・C棟すべて同じ4階が無難。5階を混ぜるなら1棟） | 金沢の緑住宅 4階建20棟・5階建13棟（S45〜49）。平和町は昭和28年が3階建 |

| 住戸の間口・棟の長さ | 住戸間口 約4.5〜5m、24戸棟の桁行 約30m前後、奥行き 約9〜10m | 赤羽台41号棟 建築面積374㎡/4階段から逆算した目安。**数値は既定（要確認）**。絵では「間口の狭い窓の連続」程度に留める |
| 1階の高さ | 1階の玄関は地面から約4段上がる | 緑住宅（金沢）PLAN-ZENHAN.pdf【単独】 |
| バルコニー | 南北両面に吹き放しのバルコニー（サンルーム化していない） | allabout 439166・432073【複数】、平和町の後年サンルーム化04_1.pdf |
| 外壁の色 | 白〜灰白のコンクリート色＋縦の雨だれ | 「白い」はユーザー設定。出典での確認は**取れていない**。雨だれは一般論の参考のみ。既定（要確認） |
| 屋根 | 陸屋根（水平）＋パラペットの縁、庇は最小限 | 出典なし。平成の建替で勾配屋根が特徴に挙がる（川辺団地）ので昭和原型は陸屋根と推測。既定（要確認） |
| 棟名 | 「A棟」でなく「○号棟」の表示を壁面に大きく（ゲーム上の呼称はA・B・C棟のままでよい） | 金沢の県営は「36号棟」等【単独】 |
| 配置 | 南面平行の板状3棟。棟間隔＝棟高さの約1.8倍（4階建で約20m）。間に中庭（広場・遊び場）、敷地隅に集会所 | 棟間1.8倍は公団の団地設計要領【単独】。金沢の県営は遊び場・集会所・緑地が実在（平和町・緑住宅）。ミニチュア工作風なら圧縮してよい |
| 中庭に置く物 | 児童遊園（砂場・滑り台）、桜など落葉樹の並木、自転車、物干し | 児童遊園・桜並木は公団の団地設計要領/金岡団地【単独・公団】。自転車・物干しは一般的な生活の跡として既定（要確認） |
| 団地内の風呂 | 棟とは別に公衆浴場（煙突付き）を敷地内に置く案 | 緑住宅は団地内に公衆浴場を設け住戸は浴槽設置スペースのみ（H3廃業）PLAN-ZENHAN.pdf【単独・市営】。県営への適用は要確認 |
| 雪 | 屋根は陸屋根のまま。冬の場面は階段室と中庭の雪、除雪された道端の雪山程度 | 昭和の団地の雪対策は**確認不可**。既定（要確認） |
