# エリア景観調査 C（noto_train／noto_before／noto_after／sunnyland／overseas）

調査日 2026-11-02。リポ資料は origin/main の docs を展開して読み取り専用で参照（台帳は変更していない）。
信頼度: 高=公的資料・百科事典を開いて本文確認 / 中=報道・観光サイト・検索結果の要約 / 低=1件のみ・要約のみ。
「仮想」と書いた部分は実景の事実ではなく、ゲームの見た目の指定案。

## 0. 先に押さえる設計上の前提（リポ資料から）

- 鉄道は**架空の「奥能登鉄道」**。実在の路線名・形式名・企業名はゲーム内に書かない（decisions.md「能登線という実在はない」2026-10-19）。車両は半クロスシートの気動車、座席はオレンジ（決定済み。noto-railway-interior-v2-diorama.png で作成済み）。以下の実在のと鉄道の調査は**質感の根拠**であって、名称は使わない。
- 駅は**実在しない合成駅**（飯田・小木・蛸島の特徴の足し合わせ。蛸島は仮称）。終点・低地・車止めで線路が終わる。能登の海は画面の下側。
- 被災後は奥能登鉄道は廃線。NTR-01・駅は残骸として残るか塞がるか未決。被災後は被災前と同じ配置で崩れる（FF6 の世界崩壊前後の趣向）。
- 能登の MAP はいずれも地区固有の建物台帳は空。木は NTB/NTA=杉+低木の茂み、NTR=未決、SNL=杉、OVS=枯れヤシ+枯れ低木。
- 世界設定は温暖化の末の寒冷化（氷河期のよう）。海外も冬。日本の冬=湿った綿の雪・灰青の曇天・暖色の窓明かり。

### 3. 冬の姿
- 実景の冬（確認できた事実）: 寒冷地仕様（ステップ・トイレの凍結防止ヒーター）が車両にあった、まで。車内の結露・雪の具体的描写は**確認できなかった**。
- 一般論（仮想の根拠）: 暖房の効いた車内の窓は外気との温度差で曇る。

### 4. 冬の景色の仮想表現（MAP 指定にそのまま書ける）
- **【仮想】座席**: 通路を挟んで両側に、向かい合わせの 4 人掛け箱席が 3 組ずつ並ぶ。背もたれと座面はオレンジのモケット（毛足の短い布）、角は擦れて色が褪せ、座面に細かな折り目。背もたれ上端は薄いベージュの地肌。赤は混ぜない（決定済みの色）。
- **【仮想】窓**: 各箱席の間に 1 枚の固定窓。下半分は結露の水滴と曇りで白く、上半分は鉛色の空と雪を吹き付けられた海岸線が透ける。サッシは薄いアルミ色、窓下に小さな水の筋。
- **【仮想】床と壁**: 床は暗い灰緑の油引き床に、雪解け水の濡れ跡と靴跡。壁・天井は淡いクリーム色の化粧板、天井に細長い蛍光灯が点々と並び、やや黄みがかる。
- **【仮想】暖房**: 座席の下に黒い金属の暖房の吹き出し口が一定間隔、足元の床に熱で乾いた帯。
- **【仮想】入口側**: 乗降口は段差があり、ドア際に手すり（金属の縦棒）と雪を踏んだ濡れ跡。吊り革は少数（ロングシート部は無し）。
- **【仮想】台座の外周（木は未決）**: 車内のミニチュアなので、台座の縁は綿の雪と雪から覗く枯れ草。杉は置かない（未決のため）。

### 5. MAP 対応
- NTR-01「奥能登鉄道の雪で曇る窓と木製座席の車内」: 上の 4 の座席・窓・床・暖房を全部使える。「木製座席」の語は一言特徴に残っているが、決定済みはオレンジの布座席（半クロスシート）。実景（NT100）に木製座席の裏づけは無いので、**木枠の背もたれ＋オレンジ布**に折衷するか、一言特徴を直すかは要確認。

### 6. 確認できなかったこと
- NT100 形の窓・床材・吊り革・照明の具体、旧能登線の冬の車内（結露・雪）の記述。
- 木製座席の実在（NT100 は布張り）。

### 3. 冬の姿
- 確認できた事実: 北西の強い海風（間垣が必要）、荒波と波の花、珠洲の冬は降水が多い（1981〜2010 年の統計、12 月が最多）。外浦側の冬の海は荒れる。
- 確認できなかった: 奥能登の集落の積雪の様子（雪囲いの具体）、板壁の外壁の特徴、杉林の実際の植生。

### 4. 冬の景色の仮想表現
- **【仮想】家**: 黒瓦の入母屋、平入り（長い面が道に向く）。瓦は濡れて黒光り、雪は屋根の上半分に薄く載り軒先は溶けて黒が出る。外壁は下半分が煤けた焦げ茶の縦板張り、上半分が漆喰の白壁（観光資料の「白壁・黒瓦」に合う）。窓は小さく、橙色の窓明かりが一つ。
- **【仮想】風除け**: 海に面した側に、高さ 5m ほどの竹の垣（間垣）か、板を打った風除け。垣の根元に綿の雪が吹き溜まり。実在の間垣は輪島側の特徴なので、**蛸島周辺に必ずあるわけではない**。使うなら NTB-03 / NTB-05 の海側に 1 区画に留める。
- **【仮想】海**: 鉛色。岸の岩とテトラポッドに白い泡（波の花）がまとまって付き、風に飛ばされた泡が道路に点々と残る。
- **【仮想】山**: 杉は濃い緑の円錐、枝に雪。低木の茂みは枯れ茶の塊に雪帽子。
- **【仮想】船揚げ場**: 斜路のコンクリートに濡れた黒い苔。屋根付きの小屋は波板トタン、雪が薄く載る。漁具（浮き、網、発泡スチロール箱）が雪に半分埋まる。
- **【仮想】路面**: 濡れた黒い舗装、端に圧雪の灰色の線。
- **【仮想】廃校の中庭（NTB-08）**: 窓ガラスが抜けた木造 2 階建ての校舎、軒先の雪が庇を作り中庭に厚く積もる。

### 5. MAP 対応
- NTB-01 蛸島駅: 小さなコンクリートの駅舎（低い箱型、実景）、1 面 1 線のホーム、車止めで線路が終わる（実景）、外は雪の綿。駅前に郵便局・商店を示す小さな建物。
- NTB-02 漁村坂（海を背に蛇行して上がる）: 坂の両脇に黒瓦の家と石垣、海は下に鉛色で見える。
- NTB-03 小祠と畑の尾根: 杉林、枯れた畑（畝が雪から覗く）、小祠は木の小さな社と雪を載せた屋根。海は下端だけ。間垣は使うなら畑の海側。
- NTB-04 船揚げ場への急坂: 船揚げ場の屋根、漁具、斜路、波の花。
- NTB-05 黒瓦の実家と海岸道のT字: 黒瓦・白壁と板壁・窓の橙明かり。
- NTB-06 テトラポッド脇の桟橋: 荒波、白い泡、立入禁止の標識。
- NTB-07 / NTB-08 廃校: 木造校舎、校庭の雪、鉄棒と古い遊具。

### 6. 確認できなかったこと
- 蛸島そのものの集落の冬の姿（積雪量・雪囲い）。奥能登の板壁の実景。杉林の実際（能登ヒバ「アテ」の検索は不発）。蛸島に間垣があるかどうか（間垣は輪島の黒島・大沢）。
- 駅舎の素材は「コンクリート」と読める（wiki）が写真未確認。

### 3. 冬の姿
- 確認できた事実: 2024-01 に被災地で積雪（珠洲で降雪 15cm と報道。[ウェザーニュース](https://weathernews.jp/news/202401/080025/) 検索結果の題名のみで本文未確認）。
- 被災地の「冬の様子」の一般描写は確認できなかった。

### 4. 冬の景色の仮想表現（扇情的にしない・人は描かない）
- **【仮想】屋根**: 黒瓦の一部が剥がれ、そこに青いシートが張られ、土嚢か古タイヤか角材で押さえる。シートの上に雪が薄く載り、端が風でめくれる。
- **【仮想】壁**: 外壁が欠け、下地の木舞か断熱材が覗く。窓は割れ、板で塞がれる。家が少し傾き、軒が一方へ落ちる。
- **【仮想】地面**: 雪の下から土の赤茶が大きく露出し、斜面は崩れて土砂が道に流れる。地割れは細い黒い線＋段差。仮設の板を渡した部分。擁壁の一部が倒れ、積んだ石や板が崩れる。
- **【仮想】杉**: 根元から倒れた杉、途中で折れた杉（折れ口は白い木肌）。枝に雪。
- **【仮想】港と海**: 港のコンクリートの壁が持ち上がり、岸壁の下に乾いた黒い岩礁と海藻の枯れた色が覗く（隆起の実景から）。防潮柵は傾いて途切れる。
- **【仮想】電柱**: 傾いた電柱、垂れた電線（決定: 倒れた電柱・切れた配線が敵の案）。
- **【仮想】駅跡**: 傾いた駅名標識と土砂。レールの一部が雪に埋まり、車止めは撤去されて枕木だけ。
- **【仮想】仮設住宅（NTA-07）**: 白〜灰色の長屋型プレハブが並び、玄関前にスロープと階段、給水車（青〜白のタンク車）と小さな集会所。雪かきされた道。
- 色の差: 被災前は黒・白・灰青。被災後は**土の赤茶＋青いシートの青＋木の折れ口の白**を加える。光は同じ曇天。

### 5. MAP 対応
- NTA-01 被災後蛸島駅: 傾いた標識、土砂、車止めのないレール。
- NTA-02 崩れた擁壁を迂回する上り坂: 倒れた擁壁と土砂、仮設の迂回路。
- NTA-03 青いシートと折れた杉の尾根: 青いシートの屋根、折れ杉、土の赤茶。
- NTA-04 地割れを跨ぐ仮設板の下り坂: 地割れの黒い線＋渡した板。

### 3. 冬の姿

### 4. 冬の景色の仮想表現
- **【仮想・外観】** 八角形の塔状エントランス。昭和 40〜50 年代風の鉄筋コンクリート、白〜灰の壁にひび、色褪せた看板（文字は読めない塗り潰し）、割れた窓、入口は崩落して瓦礫が斜めに積もる（決定済み: 入口が崩れ車椅子で入りにくい）。屋根に雪、軒先につらら。
- **【仮想・渡り廊下】** 屋根付きの長い下り廊下、ガラス窓が曇りに雪を載せ、外は雪の森（杉）。床は剥がれたビニール床材（昭和の緑〜茶）。途中右にゲームセンター（色褪せたゲーム機の筐体の影、電気の切れた看板）。
- **【仮想・地下水族館】** 格子状に並んだ水槽。水は抜けて緑の藻の筋が残る、または水が濁って暗い。出口付近にピラルクの巨大水槽、壁際にサメの標本。蛍光灯は一部だけ点滅。
- **【仮想・屋外シャチホコ】** 大きな白いコンクリートのシャチホコ（城の屋根飾りの形）。雪を被り、ひび割れに緑のカビ・錆の筋。ラッコ館と洞窟の入口が脇にある。
- **【仮想・昭和の屋外動物園】** 狭い格子状の鉄格子の檻が碁盤目に並ぶ。檻は赤錆、床はコンクリート、雪が吹き込む。美化しない。
- **【仮想・和室宿泊棟】** 廃墟の和室が並ぶ。畳は黒ずみ、襖は破れ、障子に穴。雪明かりが入る。和風怪談の演出は足さない（決定）。
- 杉の雪の森が全体を囲む。外周は綿の雪と杉（決定）。

## 5. overseas（海外・凍結荒野と三塔）— OVS-01〜20

### 1. 一言で言い当てる実体の特徴

### 2. 実景の特徴

- 九龍城砦（香港、1993 年取り壊し）について: 屋上はアンテナ・物干し・鳩小屋の森、増築で路地の上に床が張り出し向かいと接しそうになる、光庭が格子と洗濯物でふさがれる、井戸を掘り屋上の水槽へ汲み上げる、エレベーターはほぼなく暗い階段、建築規制なしで場当たりに増築 — [各種ブログ・記事の検索要約、二次情報](https://www.untappedcities.com/kill-screen-kowloon-city-behind-these-walls/)（信頼度 低。写真・書籍 *City of Darkness* に由来すると記載）。

### 3. 冬の姿
- 決定済み: 灰褐色・錆びた赤・凍った白、青白い低い日差し、長く伸びる青い影、凍った塩原、霜をかぶった枯れヤシ、氷の張った泉、乾いた粉雪。綿の雪は使わない。

### 4. 冬の景色の仮想表現
- **【仮想・荒れ地】** 台座は灰褐色の紙粘土。ところどころ赤錆色の地層が筋として覗き、割れ目に白い霜の粉。凍った塩の平原は白くひび割れ、ひびの縁が青く光る。
- **【仮想・氷】** 透明レジンで泉や窪地の氷を作る。中に細かな気泡と亀裂。氷の表面にうっすら白い霜。
- **【仮想・風食岩】** 根元がえぐれたキノコ形の岩、風上側は削れて滑らか、風下に霜の尾。
- **【仮想・枯れヤシ】** 幹だけ残り、葉は茶色に枯れて垂れ、霜で縁が白い。凍った池の縁に立つ。
- **【仮想・都市】** 遠景は灰青の霞の中、不揃いな高さの角ばった塊が積み重なった影。窓の明かりは少数、暖色でなく冷たい白〜青。
- **【仮想・塔の外観（OVS-04）】** 左右 2 本の塔、増築の箱、錆びた配管、屋上のアンテナと水槽、ひび割れたコンクリートに霜。塔間に細い空中通路。
- **【仮想・塔内部（OVS-05〜20）】** 暗い通路、露出した配管と電線、雑居の看板（文字は読めない記号）、鉄の扉、洗濯物でなく霜の付いた干し物、行き止まり。階を追って増築の継ぎ目が増える。
- 日本の冬（湿った綿の雪・灰青・暖色の窓）と差を出す: 乾いた氷、青白い光、赤錆。
