# 昭和の量産型RC団地（県営住宅）の構造 調査メモ

調査日: 2026-11-02。凡例: 【複数】= 2つ以上の出典で一致、【単独】= 1出典のみ、【推測】= 出典に直接はなく推論（採用は慎重に）。
注意: 公団（日本住宅公団/UR）の資料が中心で、県営住宅そのものの仕様書は取れていない。公団は公営・公務員住宅の標準設計を土台に作ったと出典にある（下記）ので近縁だが、同一ではない。

## 1. 標準的な間取り

- 公営住宅の標準設計「51C型」は 1951 年度。約 35㎡（約 12 坪）。食寝分離（食べる所と寝る所を分ける）。台所を広めにとり食事も兼ね、居室2つ（6畳＋4.5畳）を置いた。【複数】
  - https://www.nomu.com/mansion/library/trend/history/ide02.html 「51C型は約35㎡」「食寝分離」「公営住宅51C-N型 = 後の2DKの間取り（40.2㎡）」
  - 検索結果要約（tsukuba.repo.nii.ac.jp の博士論文、本文は未読）: 6畳・4.5畳の居室2つ。※この行の畳数は検索要約のみで、ページを開いて確認はしていない【単独・弱】
  - 注: 51C が2DKの直接の源流かは学説が割れる（鈴木成文は無関係と主張、nomu 記事）。
- 公団は設立後 1955 年に「55型」標準設計を整備。「公営・公務員住宅の標準設計を活用し」と明記。55-3.4N-2DK 型は 13.0 坪。
  - https://www.ur-net.go.jp/rd_portal/archive/lrmhph000001t9d7-att/p14-p15.pdf（pdftotext で本文確認）
  - 同 https://www.ur-net.go.jp/rd_portal/pnf/ing_report_juu/hndcds000000a2i8-att/hndcds000000abfn.pdf に「4階建て北入りの階段室型」2DK、モジュール 800mm（畳短辺 800mm）、「団地サイズ」と批判され 67型で 900mm に。
- 「2DK/3DK」の呼称は公団が作った（初代設計課長・本城和彦）。nomu 記事【単独】。
- 1967年の標準設計 67-5N-3DK は「5階建て北入り階段室型」。UR p14-p15【単独】。
- 金沢の県営住宅の具体的な間取り図・畳数は確認できなかった（7 参照）。

## 2. 棟の構造と外観

- 中層住宅のアクセスの基本は「階段室型」（北入り=N型、南入り=S型）。片廊下型は C 型（コリドール）、中廊下型は MC 型で、ラーメン構造や施設付き住棟に多く採用された。【複数】
  - UR p14-p15 「中層住宅のアクセスの基本は階段室である」「片廊下型をC型…ラーメン構造や施設付き住棟などに多く採用」
  - https://allabout.co.jp/gm/gc/432073 「多くでこの階段室型が採用されています」「3～5階建て」「2戸が1つの階段室を共用」「南北両面にバルコニー」
- つまり「各戸の入口が廊下に面する」のは**片廊下型（C型）**。公団では階段室型が主流で、片廊下型は少数派。県営住宅が片廊下型だったかは確認できなかった（棟の型の指定は設計意図として別途決める）。
- 階数: 団地は 1960〜70 年代に「5階建てまで」。エレベーターなしが多い。https://ja.wikipedia.org/wiki/団地 【単独（百科事典、二次資料）】
- 金沢・平和町団地（県営）: 昭和28年に「中層RC造3階建て」の県営住宅から整備開始。昭和54年度には 49棟916戸、県下最大。建設は昭和40年代末までにほぼ終了。
  - https://www.pref.ishikawa.lg.jp/kenju/jusei_pamph/documents/04_1.pdf（pdftotext で本文確認）「中層RC造3階建ての県営1号・2号棟を皮切りに」「昭和54年度には49棟916戸」
  - 同資料: 「バルコニーをサッシュで囲いサンルーム化」「外壁明装」の改善事業（昭和57年〜）。つまり**元のバルコニーは吹き放し**、外壁は後年に色を変える対象だった。
- 工法: 公団はPC（プレキャストコンクリート）板工法、MF（メタルフォーム）工法を導入。当初は在来工法。「公共住宅全体で中層PC住宅が建設されている」。https://www.ur-net.go.jp/rd_portal/pnf/ing_report_juu/hndcds000000a2i8-att/hndcds000000abfn.pdf 【単独】。ただし「白い」外壁の根拠は取れていない。
- 窓の種類（アルミ/スチール）、手すりの材質、外壁の色: 確認できなかった。

## 3. 廊下と玄関扉

- 玄関ドアは「鉄扉（玄関ドア）一枚」で住戸を隔てている、との記述。https://ja.wikipedia.org/wiki/団地 【単独】（団地妻という語の説明内）
- 公団は「ステンレス流し台やシリンダー錠など、まだ日本になかった部品を自ら開発・供給」。UR p14-p15。→ 玄関まわりの錠はシリンダー錠が量産部品【単独、公団】
- 郵便受け・のぞき窓・チャイム・表札・廊下の腰壁・生活の跡（洗濯物など）: 確認できなかった。

## 4. 室内の仕上げと設備

- 台所: 公団は流し台を「人造石研ぎ出し製」→ステンレス流し台へ改良。https://www.ur-net.go.jp/rd_portal/pnf/ing_report_juu/hndcds000000a2i8-att/hndcds000000abfn.pdf（本文に「人造石研ぎ出し製から」の記述）【単独】
- 住戸に水洗トイレ・風呂・ダイニングキッチン・ベランダが備わったのが公団住宅の新しさ。https://ja.wikipedia.org/wiki/団地 【単独】。また 検索要約: 「2DKの住戸には流し台や水洗トイレ、内風呂」柏市資料（本文は未読）。
- DKは襖で居室と仕切る構成。nomu 記事: 「DK側の襖と壁・押入で仕切る」。
- 壁・天井仕上げ（ペンキ/ビニールクロス/打放し）、床（畳/板/クッションフロア）、押入の位置、電気設備: 確認できなかった。

## 5. 風呂なしと銭湯

- 公団（URの前身）は最初から浴室を設けた。木製浴槽→昭和38年頃ホーロー（800×700×640mm、180L）へ。浴槽の横に 300mm の風呂釜設置スペースを確保して浴室の幅とした。https://www.ur-net.go.jp/rd_portal/pnf/ing_report_k/lrmhph000000jl2p-att/ing_ki.pdf（pdftotext 確認）
  - 風呂釜は CF 釜・BF（バランス）釜タイプが図示されている。
- 公営住宅では「浴室はあるが浴槽も風呂釜も給湯器もない」住戸が珍しくなかった。浴槽・風呂釜は入居者が自費で設置（最安で約30万円、退去時の撤去に約10万円）。浴室には蛇口が1つだけ、という例。https://www.ben54.jp/news/2649 【単独（弁護士ドットコムニュース）】
  - 大阪市は浴槽設置事業として市費で浴槽等を設置（https://www.city.osaka.lg.jp/toshiseibi/cmsfiles/contents/0000685/685357/R8-9_18-19.pdf で「浴槽設置工事」の記載を確認）【複数: ben54 と一致】
- 重要: 出典は「浴室スペースはあるが浴槽（と釜）が無い」と述べる。「浴室そのものが無い」とは言っていない。ゲーム設定の「浴槽がない」と整合するのはこちら（浴室は蛇口のみ・窓の下に洗い場スペース的な空間、が根拠付きで描ける）。
- 銭湯は生活保護世帯には家計的に厳しく現実的でないとの記述あり（ben54）【単独・現代の話】。昭和当時の銭湯利用の記述は確認できなかった。

## 6. 雪国の特徴

- 石川県の豪雪地向け住宅に高床、雁木（歩行空間の屋根）、載雪型屋根という工夫があるが、これは**木造・特定公共賃貸**の例で、昭和のRC団地の記述ではない。https://www.pref.ishikawa.lg.jp/kenju/jusei_pamph/documents/09_1.pdf（検索要約のみ、本文は未読）
- 昭和の金沢の県営RC団地の雪対策（庇・二重窓・廊下の雪）: 確認できなかった。

## ゲーム背景に反映する時の注意（出典に基づくもの）

- 和風の木造風（木の柱、漆喰、瓦、縁側）は誤り。RC造の中層（3〜5階）棟で、外壁は大面積のコンクリート。バルコニーは吹き放し（後年のサンルーム化は別）。
- 居室は2つ＋台所（DK）。DKは食事兼用で、居室との間は襖か壁・押入。畳の6帖・4.5帖が51C系の目安。ただし洋風化の度合いは県営の資料で未確認。
- 入口は鉄扉1枚。廊下側に入口があるなら片廊下型（公団では少数派。階段室型が主流）。県営でどちらかは未確認。
- 浴室スペースはあっても浴槽・釜が無い、は公営住宅で実在した（蛇口のみ）。「浴室ごと無い」とは出典は言っていない。
- 流し台はステンレス（公団標準）。木の台所ではない。
- 隣戸との境は鉄扉・コンクリート壁（戸境壁）。仕上げの色や質感は未確認なので、描くなら控えめな無地にとどめる。
