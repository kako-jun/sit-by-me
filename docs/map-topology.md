# マップのトポロジー計画（地区ごとの枚数・つながり・道の形）

作成: 2026-10-15（kako-jun の指示「トポロジー・道の角度やぐにゃぐにゃ・全何枚・接続位置を計画しろ。でないと今作ったものも最終画像にならない」）。

- 目的: **絵を作る前に**、どの場所がどの場所と、どの辺の、どんな形の道でつながるかを決める。足りない絵・無駄な絵・再生成を出さない。
- 前提規則（`.claude/skills/sit-diorama/SKILL.md`）: (1) 出た辺の**反対の辺**から入る、(2) 道の向き（横・縦・斜め）が大きく食い違わない。幅・位置・傾きは目安（エンジンが相対位置で合わせ、フェードで切り替える）。
- **無駄な作成をしない**（kako-jun 2026-10-15）: 既存の絵を最大限使い、本当に要る「つなぎの絵」だけを新規にする。再生成・v2 は明示指示があるときだけ。
- 辺と道の形は、既存の絵を目視して書いた目安。生成・採用の前に再確認する。範囲（`range`）の画素値は、地図 JSON（`masks/*-map.json`）を作るときに決める。

## 1. 道の形を単調にしない方針

同じ地区の中で、隣り合う絵の道の形が同じにならないようにする。使う形の語彙:

`横直線` / `縦直線` / `斜め（右上がり／右下がり）` / `L字` / `T字` / `十字` / `S字（ぐにゃぐにゃ）` / `広場（出入口が複数）` / `石段・坂（縦）` / `桟橋・防波堤（細い帯）` / `屋内（ドア遷移のみ）`

- 隣接2枚で同じ形（横直線→横直線）を続けるのは、**間に個性のある場所（ランドマーク）がある場合だけ**。
- 通路的な絵（道だけの絵）は、1つの地区に**せいぜい1つ**（art-direction）。新規のつなぎの絵は、すべて「川・橋・松林・坂」など地形の個性を持たせる。
- 直線の続く所は**ぐにゃぐにゃ**（S字・緩い弧）にして、歩く方向を変える。

## 3. 地区ごとのグラフ

表記: `A.辺[位置] ⇄ B.辺`（辺は top/bottom/left/right、反対の辺で入る）。道の形は括弧。ドアは「辺ではなく遷移ゾーン」（name-name #842）。

### 3.1 寺町（既存13枚・新規0）

既存の連絡（`teramachi-map.json` の実装済み）:

```
kindergarten.bottom ⇄ connector.top      （縦の石畳→縦の道）
connector.right    ⇄ hinomi-bend.left    （右上がり斜め）
hinomi-bend.right  ⇄ wide-road.left      （横）
hinomi-bend.bottom ⇄ narrow-lane.top     （縦の路地）
wide-road.right    ⇄ well-merge.left     （横）
well-merge.right   ⇄ sento.left          （横→斜め）
sento.bottom       ⇄ barrier-free-ramp.top  （縦。車椅子の経路）
barrier-free-ramp.bottom ⇄ danchi-court.top （縦）
danchi-court.top   ⇄ old-slope-foot.bottom  （縦の石段。立てる時期のみ）
old-slope-foot.top ⇄ slope-top.bottom   （縦の石段。立てる時期のみ）
```

追加する連絡（**新規の絵は要らない**）:

| 追加 | 内容 |
|---|---|
| `wide-road.top[門の位置] ⇄ temple-grounds.bottom` | 広い道路の北側の門から、境内へ入る（縦の石畳）。境内は行き止まりの敷地 |
| `temple-grounds` →（庫裏のドア）→ `temple-residence-interior` | 屋内。ドア遷移（#842）。台所・板の間・幼馴染の部屋 |
| `connector.bottom（左寄り・斜め）` を **香林坊側への出口**として使う | 3.2 の N2 とつなぐ |
| `narrow-lane` の行き止まり | 路地の奥の山門は、行き止まりでよい（寺の勝手口）。つなぎは増やさない |

道の形の並び（寺町の主線）: 縦（幼稚園前）→ 斜め（connector）→ 弧（日の見の曲がり）→ 横直線（広い道路）→ 緩いS字（井戸の合流）→ 斜め（銭湯）→ 縦（スロープ）→ 広場（団地）→ 石段（縦）。**単調でない**（既に十分）。

注意: `kindergarten` は園庭と寺の建物（本堂・山門）が1枚に入っており、`temple-grounds`（境内）と見た目が一部重なる。幼稚園は「寺が運営する私立」なので、境内は園の裏手として扱い、2枚とも残す（重複として削除しない）。

### 3.2 香林坊・茶屋街・病院（既存7枚・新規2枚）

序盤の流れ: 劇中断 → 運動場 → （親とワープ）香林坊 → 大和のおもちゃ売り場で刀とスマホ → 上の階のレストラン → 戻り道（茶屋街・コンビニ・幼稚園）で敵が出る冒険。

```
korinbo-crossroads（十字）
   ├─ ドア ⇄ korinbo-daiwa-toy-floor   （屋内。エスカレーターで上の階へ）
   │        └─ エスカレーター ⇄ korinbo-department-restaurant (v2)  （屋内）
   ├─ right[横] ⇄ chaya-lane.left      （横）
   └─ left[横]  ⇄ hospital-exterior.right （斜め：病院は壮年の最後の1日で使う）
chaya-lane（L字: 左から入り、右で折れて下へ）
   ├─ ドア ⇄ chaya-tearoom             （屋内。茶室）
   └─ bottom[縦] ⇄ N1.top
N1 川沿いの曲がり（新規）: 浅野川のS字。上から入り、右へ流れて出る
   └─ right[横] ⇄ convenience-store.left
convenience-store（横直線）
   └─ right[横] ⇄ N2.left
N2 寺町への坂道（新規）: 左から入り、緩い坂で上り、上の辺へ抜ける（右上がり→縦）
   └─ top[縦] ⇄ teramachi.connector.bottom（左寄り）
```

道の形の並び: 十字 → L字 → S字（N1）→ 横直線（コンビニ）→ 坂（N2）→ 斜め（寺町 connector）。同じ形が連続しない。

新規2枚の個性（通路的な絵にしない）:
- **N1**: 川（浅野川）に架かる橋のたもと。S字に曲がる川岸の道、橋、柳か桜の枯れ木。茶屋街から来て、コンビニの駐車場へ抜ける。
