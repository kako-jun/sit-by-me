# マップのトポロジー計画（地区ごとの枚数・つながり・道の形）

作成: 2026-10-15（kako-jun の指示「トポロジー・道の角度やぐにゃぐにゃ・全何枚・接続位置を計画しろ。でないと今作ったものも最終画像にならない」）。

- 目的: **絵を作る前に**、どの場所がどの場所と、どの辺の、どんな形の道でつながるかを決める。足りない絵・無駄な絵・再生成を出さない。
- 前提規則（`.claude/skills/sit-diorama/SKILL.md`）: (1) 出た辺の**反対の辺**から入る、(2) 道の向き（横・縦・斜め）が大きく食い違わない。幅・位置・傾きは目安（エンジンが相対位置で合わせ、フェードで切り替える）。
- **無駄な作成をしない**（kako-jun 2026-10-15）: 既存の絵を最大限使い、本当に要る「つなぎの絵」だけを新規にする。再生成・v2 は明示指示があるときだけ。
- 辺と道の形は、既存の絵を目視して書いた目安。生成・採用の前に再確認する。範囲（`range`）の画素値は、地図 JSON（`masks/*-map.json`）を作るときに決める。

## 1. 道の形を単調にしない方針

同じ地区の中で、隣り合う絵の道の形が同じにならないようにする。使う形の語彙:

`横直線` / `縦直線` / `斜め（右上がり／右下がり）` / `L字` / `T字` / `十字` / `S字（ぐにゃぐにゃ）` / `広場（出入口が複数）` / `石段・坂（縦）` / `桟橋・防波堤（細い帯）` / `屋内（ドア遷移のみ）`

- 隣接2枚で同じ形（横直線→横直線）を続けるのは、**間に個性のある場所（ランドマーク）がある場合だけ**。
- 通路的な絵（道だけの絵）は、1つの地区に**せいぜい1つ**（art-direction）。新規のつなぎの絵は、すべて「川・橋・松林・坂」など地形の個性を持たせる。
- 直線の続く所は**ぐにゃぐにゃ**（S字・緩い弧）にして、歩く方向を変える。


- **イベントシーン**の扱い: 砂漠の2枚は、短く歩ける固定の一枚絵（またはスクロールしない移動の演出）で、**空港→都市の距離感を見せるための場所**。レベル上げの量には数えない（最小限のエンカウントのみ）。

- 道の形: 空港（広場）→ 砂漠A（横の一本道・遠景に都市）→ 砂漠B（起伏・分岐）→ 都市（垂直）。**海は無い**（海の位置の規則の対象外）。
- **季節は海外も冬**（kako-jun 2026-10-15）。**地球温暖化が進み、氷河期のようになっている**世界。海外だけ暑いのではなく、日本と同じく凍てついている。
- **テンプレのような砂漠にしない**（kako-jun 2026-10-15）: 黄土の砂丘が波打つ・ラクダ・ヤシ・灼熱の青空、という典型は使わない。**ただし「オアシスだったもの」は出してよい**（kako-jun 2026-10-15。凍りついた池、枯れて霜をかぶったヤシ・低木、氷の張った泉、かつての水場の跡など。宝箱の行き止まりや見せ場に向く）。

- 日本の冬は**湿った綿の雪・灰青の曇天・暖色の窓明かり**なので、海外は**乾いた氷と霜・青白い光・長い影・赤錆と灰褐色**で差をつける（同じ冬でも、質感・色・光を変える）。

## 9. 道の構造ルール（一本道に見せない・歩く向きを散らす・宝箱の行き止まり）

kako-jun 指示（2026-10-15）:
- マザーのように**左右移動が中心でよい**が、たまには**上下や斜め**も必要。
- 一本道に見えないために、**丁字路（T字）や交差点（十字）**は必要。
- **宝箱を置くための行き止まり**もあってよい。
- 能登のように土地の起伏が激しい地区は、**町から町の間で一度高台へ上り、また降りる**構造にする。

### 9.1 地区ごとの配分の目安（歩ける屋外の枚数に対する割合）

| 要素 | 目安 | 数え方 |
|---|---|---|
| 横の移動が主な絵 | 約 50〜60% | 道が左右の辺をつなぐ |
| 縦・斜めの移動が主な絵 | 約 25〜30% | 上下の辺、または斜めの道 |
