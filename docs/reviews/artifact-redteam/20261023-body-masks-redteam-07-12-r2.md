- **BDY-09 W（3,098px の追加分）**: 床色の本体は妥当（x=130 以降が床、profile (239,206,174) 等）。ただし x=124〜129 の 6px（RGB (204,167,129)→(167,123,81)）は床ではなく、床と段ボールの縁の間の茶色の細い帯（wall 側の縁）。md>15 の成分 575px（x124〜129, y267〜379）・232px（y231〜265）・256px（x124〜147, y386〜405）。さらに y=218〜226 の x=128〜144 に長方形の突起（116px）。白は帯を跳び越えてはいない（x=122 で black、さらに外の段ボール・黄テープの面には届いていない。クロップ `r2/c09_west.png`）が、床と縁の帯 6px へ白がはみ出している → F-R2-01
