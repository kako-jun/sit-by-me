## 先に固定した契約

`E09` は立てる時期だけ使う古い石段の下であり、車椅子主路ではない。正本の相互接続は `E08.right ↔ E09.left`、`E09.top ↔ E13.bottom` である。したがって E09 単体では、**left edge から入った立位者が幅の読める石段を通り top edge へ抜ける**必要がある。bottom/right に外部へ続く道を出してはならない。石段の閉鎖時期・通行クラスは後続の三値maskで定義する。

依頼文中の `E08.left → E09.left` は正本と辺名が食い違うため、E08側の正しい相手端 `E08.right` を優先した。今回の原画像で検査できるのはその相手である `E09.left` と `E09.top` である。

## 所見と処置

### blocker — `E09.top` が edge link になっていない

**根拠:** 原寸の上端中央では石段が土台外縁へ届かず、石段上端と画像上端の間に背景が挟まる。これは `E09.top ↔ E13.bottom` の画像端接続を満たさない。maskは画像外にリンクを捏造できないため、現候補にmask工程を進めても修復不能である。

**修正先:** 生成作者は `docs/teramachi-rebuild-candidates.md` のE09候補を `blocked-regenerate` のまま維持し、E09 v5では left edge から石段下端へ入り、石段上部の平坦な踊り場または通路が **top edge まで実画素で到達する**構図に再生成する。bottom/rightは引き続き閉鎖する。再生成後、立位期のみの `orange` と事故後閉鎖の `black`、`E08.right` と `E13.bottom` の `links` を持つmask一式を添えて、別の独立red-teamへ渡すこと。

### minor — 候補台帳の版番号がv3のまま

`docs/teramachi-rebuild-candidates.md` のE09行はv3候補のみを指しており、v4のraw pathと本レビューへのリンクが未記録である。v4は不合格なので採用先へ差し替えてはならないが、作者側は失敗候補の追跡としてパスとこのレビューを追記する。

## 最終判定

**blocker / mask工程不可 / 採用不可。**

v4はleft edge入口、禁止辺、雪国の手作り模型性、人物・文字なしを満たす。しかし `E09.top` が画面端に到達せず、`E08.right → E09.left → E09.top → E13.bottom` の往復可能な接続を成立させない。maskなしで採用不可であることに加え、今回の画像はmaskを作っても接続不足を解消できないため、まず再生成が必要である。候補画像自体は本レビューで変更していない。
