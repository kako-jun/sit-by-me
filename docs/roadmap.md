### 作業の進め方（この設計セッションで学んだこと）

- 実装・テスト作成・レビューは、サブエージェント経由。レビューは opus。
- **サブエージェントの報告を信じない。** 毎回、(1) `origin/main` の全テスト名が残っているか（`comm` で突き合わせ）、(2) `git diff origin/main...HEAD` の削除行、(3) テストの実行を、自分で確認する。実際に、修正担当が自作のパッチで既存テスト15件を消す事故があった。
- テストは、**変異テスト**で感度を確かめる。定数を参照するだけのテストは、定数の値の変更を捕まえられない。仕様で固定された値は、リテラルで固定する回帰テストを書く。
- 画像生成は、`codex exec` の `$imagegen`。依頼した大きさ（3840x2160）より小さく（1672x941 前後）返る。人物は必ずイラスト調に指定する（実写寄りだと実在の人物に見える）。
- 今は、キャラ画像は仮のテンプレ絵。ポーズ一式（タイル生成 #5）に進む前に、キャラの特徴づけ（#7）を決める。
