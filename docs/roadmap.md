## 試作（sit-by-me#1）

冒頭の幼稚園の劇戦闘の1本だけを作る。立てる4人（主人公・幼馴染・友達2人）がサイドビューで、段ボールのドラゴンと戦う。

確認すること:
- アクスタ表示が成立する（透明な余白と枠線、台座、影。実写っぽい生成背景でも境界が読める）
- サイドビュー戦闘が成立する（敵が左、味方が右、下にコマンドと味方全員の HP）
- 実写っぽい生成背景が成立する

素材は実写っぽい生成画像で作る。

## 完了の基準

- 「テストが通る」「型が通る」は完了の根拠にならない。ブラウザで実際に golden path を踏み、仕様に書かれた挙動を目視してから完了とする。
- 見た目が変わる変更は、静止画の並置ではなく、ライブでの切り替え比較で確認する。
- 目視は kako-jun 本人が実ブラウザで行う。
