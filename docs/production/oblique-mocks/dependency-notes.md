## 要確認（kako-jun に聞く）
1. **TRM-06 が TRM-03 に依存するか**: 住居の裏の外壁（TRM-06 の house）は TRM-03 の住居と同じ建物のはず。依存とすると TRM-03 確定後に作る（現状: 依存あり）。外壁の様式が TRM-05 の室内壁だけで足りるなら TRM-05 のみでよい。
2. **TRM-07（山門・寺の長塀）・TRM-16（寺門・土塀）・TRM-17（寺の屋根・黒瓦）が TRM-03 に依存するか**: 寺の建物（山門・寺門・屋根・塀）の様式を TRM-03 の外観と共有するなら TRM-03 が親（現状: 依存あり）。共有しない（別の建物）なら独立で並列にできる。
3. **用水（TRM-08・16・17）・消雪パイプ（TRM-07）などの共通の地物**: 同じ用水・水路の見た目を複数枚で描く。共有とみなして最初の1枚（例: TRM-16）を親にするか、各MAPで独立に作るか（現状: 独立。道の端の連続だけを共有とみなさない）。
4. **隣り合う屋外の道どうしの端の連続**（地面・雪・縁石の見た目の一致）: 並列で作ってから端を調整するか、隣へ順に渡すか（現状: 並列）。
5. **TRM-05-kids・-fire が TRM-03 の前に必要か**: 外観は時期で変わらない前提で、-kids・-fire の確定を待たない（現状: TRM-03 の親は 04・05・02 のみ）。
