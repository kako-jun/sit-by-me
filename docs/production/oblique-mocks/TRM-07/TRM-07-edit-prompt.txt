# oblique-edit-prompt/5 TRM-07

ROLE: 添付のモック画像（色付きの箱で作った間取りの斜め見下ろし図）を編集して、手作りミニチュア（段ボールの台座・綿の雪・紙粘土の木・木目の床の工作）の一枚絵に仕上げる。モックは**位置と大きさを正確にするための型**で、見た目の完成形ではない。
GEOMETRY（固定。ここだけが『足さない・消さない・ずらさない』）: 固定するのは幾何を決める要素だけ: 画像の寸法・視点・各層の境界（作業机/台座/台座の前縁/境内の地面/建物）・壁の位置と高さ・戸口の位置と幅と高さ・窓の位置と数と種別・家具の箱の位置と大きさと高さ。位置と大きさは下の COORDINATES の画素座標で与え、1画素も動かさない。『足さない・消さない・ずらさない』はこの要素に限る。
FILL（装飾。簡素にしない）: 装飾を許すのは『指定のない面の内側』（壁の面・床の面・棚や机の上・舞台の背景・建物の外の雪面・作業机・台座の前縁）だけ。建物の輪郭（壁の外形・壁の高さ・柱の位置・戸口・窓・家具箱の外形）を描き直す許可ではない。これらの外形線は COORDINATES の画素座標どおりに描き、建物全体を上下左右へずらさない。面の内側は簡素にせず、自然な工作の装飾（素材の凹凸・継ぎ目・小物・植物）で十分に埋める。
REALITY（屋外。現実の写真・資料は形・配置・材質の種類・経年の参考にする）: 添付のモックと座標は『最低限こういう位置関係にしろ』という位置の指定にすぎない。建物の形・家・庭・道との境界・植栽・木の大きさなど位置以外は、下に書いた具体的な描写（現実の写真・資料を参考にした材質・色・形・経年・雪の載り方）に従い、工作の素材の質感で細部まで作り込む。道と私有地・敷地・水際・段差の境目を『色の違いだけ』にしない。土塀・石垣・生垣・板塀・縁石・段差・石段・護岸・閉じた門や景色としての扉など、実体のある要素として、工作の素材で立体的に作る。歩けない場所は、段差・塀・閉じた門・水などの視覚的な理由があって歩けなさそうに見えること（入れそうな地面に見せない）。観光地の有名な建物の特徴を混ぜず、一般の景観として描く。
ROAD EDGE: 道路・街路・路地・坂など歩く道がある場合、その道の両脇には必ず、段差・塀・側溝・縁石・護岸・石垣・生垣など実体のある境界を立体で描く。道の外側が歩けるように見えてはいけない（道の地面がそのまま外へ続いて見える道端にしない）。歩けない場所は歩けなさそうに見えること。通れなくする手段は1種類に固定せず、現実の寺町・町並みの写真・資料に基づいて区間ごとに使い分ける（同じ塀が延々と続く単調さを避ける）（歩く道が無いMAPでは何も足さない）。
SHOSETSU: 消雪パイプの散水ヘッドを描く場合は、穴だけを描く。穴は道路の中央線の上にだけ、等間隔で一列に並べる（道が斜め・S字のときは、道の中央を走る線に沿って）。路肩・歩道・縁石際・路面の端・私有地・石畳の参道には置かない。路面と同じ高さの丸い穴と、その周りの錆色の輪・濡れた艶・雪の溶けた輪だけを描き、水の噴射・飛沫・水の柱・霧は描かない（静止画では水が動かず不自然になるため）。消雪パイプが無いMAPでは何も足さない。
寺町の木は大きさが均等でない（TREES の枠で）。普通の木のほかに、飛び抜けて高い古木（巨木）を境内・門前などに混ぜる。
MINIATURE MATERIALS（屋外・屋内の全MAP共通。REALITY より優先する）: 画面のものはすべて、手作りミニチュア（ジオラマ）の工作の素材で作った模型として描く。現実の写真・資料は形・配置・材質の種類・経年の参考にするだけで、見た目は常に工作の素材感にする。雪は綿（脱脂綿・ポリエステル綿を盛り、ちぎった質感）で、屋根・塀・地面・木の枝に載る雪もすべて綿。瓦・土塀・石垣・石積みは紙粘土・石粉粘土・スタイロフォーム・紙やすりの質感。木は紙粘土の幹とスポンジ・綿の葉。水・氷はレジンや透明樹脂の質感。舗装は紙やすりや黒紙の道。塗装は筆跡が見える。撮影した模型の写真として仕上げる。
