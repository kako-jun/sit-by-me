- 系統的な理由の候補（要・目視）: 机の上の積み木・机に寄せた椅子（plan で許可）・棚の天板の小物が箱の輪郭の外へ出て、箱の外接輪郭がその分変わって見えている。領域ずれの測定は『箱の輪郭帯を生成輪郭の距離場へ平行移動で当てる』方式なので、許可した装飾で輪郭が増えると家具の領域では取り違える。モック自身を入力にした自己較正は輪郭が疎なため、この種の取り違えを検出できなかった。→ **家具の領域ずれは装飾込みでは信頼できない測定**。窓・戸口・壁（建物の輪郭）のほうが信頼できる。

## 合格基準を満たしていない → 案3の設計提案（ここで止まる）
目的: 建物の輪郭（幾何）は絶対にずらさず、装飾は最大限に作り込む。幾何を生成の「外」で決定論的に保証する。

### 工程
1. **層の分離（決定論）**: `layer_masks` と同じ幾何から、(a) 建物（壁の外形の凸包＋余白の羽根）、(b) 建物の外（台座の上面−建物）、(c) 作業机・台座の前縁、の3マスクと、建物の外接矩形 [313,175,1360,762] ＋余白 24px を出す。
2. **外周の生成（外景・机・台座）**: 入力＝モックの建物領域を単色の箱（壁の上端線だけ残した灰色のブロック）に置換した画像。edit-prompt（外周専用: LAYERS の机・前縁・建物の外と TREES・TREE PLACEMENT のみ）で 4 テイク。建物の中身は求めない。出力から (b)(c) の領域だけを使う。
3. **建物の生成（クロップ生成）**: 建物の外接矩形＋余白をクロップして入力にし（アスペクト比を保ち 16 の倍数に拡大）、edit-prompt（建物専用: 壁・床・戸口・窓・家具の look・COORDINATES はクロップ内座標）で 4 テイク。クロップが生成のキャンバスなので、建物全体のずれが測定可能な範囲に閉じる。クロップ外（外周）は触らない。
4. **位置合わせ（決定論）**: 建物テイクごとに、壁・戸口・窓の輪郭（信頼できる領域）でモックとの剛体＋スケール（または相似・アフィン）変換を推定（ECC もしくは輪郭の Chamfer 最小化）し、モックへ重ね直す。ずれが基準（例: 平行移動 ±16px・回転 ±0.5度・スケール ±1%）を超えたテイクは捨てる。
5. **合成（決定論）**: 位置合わせ済みの建物テイクを建物マスク（外壁の外形線に沿って 3〜6px の羽根）で外周テイクに貼る。継ぎ目は外壁の接地線・上端線の上に来るので、壁の厚みの線で隠せる。
6. **測定**: 合成画像に既存の `oblique_e2_measure.py`（幾何・装飾・エリア固定）をそのまま適用。追加: 継ぎ目の勾配の連続性（合成境界の両側の色差）、建物クロップ内の窓・戸口の位置ずれ（位置合わせ後に 0〜2px のはず）、外周と建物の色・光の不一致（平均 Lab 差）。
7. **選別**: 外周 4 × 建物 4 から、測定が最良の組み合わせを自動で選ぶ（合成は決定論なので 16 通りを全部測れる）。採用は kako-jun。

### 入出力・必要な決定論ツール（新規）
- `oblique_e2_layers.py`: MAP と層マスク・クロップ矩形・外周専用入力（建物を灰色ブロックへ置換した画像）を出す。出力: `layers/{desk,outside,building}.png`・`crop-building.png`・`outer-input.png`・`layers.json`（クロップ矩形・変換）。
- `oblique_e2_align.py`: 建物テイクとモックの位置合わせ（推定した変換・残差を JSON）と、変換適用後のクロップ。
- `oblique_e2_composite.py`: 外周テイク×建物テイクの合成（羽根つきマスク）・継ぎ目の測定。
- 既存の `oblique_build.py` は edit-prompt を 2 種（外周専用・建物専用）に分けて出す（decor_pool の層・面・kinds を再利用。`outer`／`building` モード）。`oblique_e2_run.sh` に `--mode outer|building` と 16 通り選別を足す。

### 測定と採用基準
- 建物: 位置合わせ後の窓・戸口・壁の残差 ≤2px、変換の大きさが上記の範囲内。装飾は建物の領域（壁・床・家具）のエッジ密度・エントロピー比 ≥0.60。
- 外周: 机の色・板目（エリア固定）、木の塊と四辺分布、平坦白、台座前縁の密度。
- 合成: 継ぎ目の色差・勾配、全体の幾何（窓・戸口が ±8px 内）。
