### 幾何（失敗の型）
- **B案は元の採用画像の構図をほぼコピー**: 生成輪郭と ref 輪郭の Chamfer が 1.1〜3.5px（対モックは 4.9〜5.6px）。『構図・位置はコピーしない』の指示は守られなかった。モックの幾何（窓・戸口・家具の位置）に対するずれは領域OK率 0〜0.08。この案が成功しても「モックを編集元にする」設計の意味（位置の正確さ）を満たさない。

## 読み取り（数値から言えること）
1. 装飾量・外周の木と草・層の色分けは、プロンプト（A案）でかなり出せる。常緑樹と台座の前縁の段ボール断面は A では不足、B（元画像の参照）で満たす。
2. 幾何の固定と装飾の充実が両立していない。装飾を許すと、画像生成が建物を描き直し、モックの位置から約 20〜40px 動く（A）か、参照画像の構図に寄る（B）。round1（装飾なし）の幾何は保たれていたので、原因は「装飾の自由度」と「描き直し」であって、モックの精度ではない。
3. どのプロンプト部分が効いたか（因果は未分離。A と B の差のみ）: 外周の木と草の指定・層ごとの LAYERS・ALLOWED は A でも効いた（木の塊・草・層の色）。常緑樹と前縁の密度は参照画像（B）が効いた。B の幾何失敗は参照画像の添付そのもの。

## 次手の提案（kako-jun が決める）
- 案1（A案を1点だけ直す）: 仮説＝装飾を許した文面が「建物を描き直す」許可として働いている。LAYERS の『建物』に「壁の上端線・窓枠・戸口・家具の接地線の画像座標はモックの線の上に描く。壁の高さを変えない」を座標つきで足し、常緑樹の本数（8〜12本のうち4本以上が常緑樹）を明記して再生成（4テイク）。
- 案2（2段階）: 装飾画像（A/B）を幾何のずれに合わせて領域ごとに非剛体で位置合わせしてから使う（決定論の測定器に既にある領域ずれを流用）。ただし描き替えが大きい場合は破綻する。
- 案3: 幾何に影響する層（建物）と装飾の層（作業机・台座の前縁・外周）を別々に生成して合成する（外周と机は位置が緩くてよいので B 案が使える。建物は round1 方式＋壁・床・家具の小物を別途）。
- B案（元画像の添付）は構図コピーになるので、そのままの採用は勧めない。外周の木と前縁の様式の参照に限り、建物の領域を隠した参照画像を作る手がある。
