# 物語（確定事項と未決事項）

題名は **Sit by Me**。「私の隣に座って」。車椅子の人の隣に座る、という動作で成り立つ物語。

## 世界観

- **少し未来の日本**。混血や移民が進み、服装や髪の自由度も上がった世界。
- 登場人物は、全員を「日本人の見た目」に固定しない。髪色（白髪、部分染め、エクステ）、肌、顔立ち、服装（開放的な服装）の幅を持たせる。誰が混血や移民のルーツを持つかは未決（キャラデザインの Issue）。
- 実写の背景は、いまの日本の風景をそのまま使う。未来感は、人物の多様さと服装・髪の自由度で出す（背景を未来的に加工することはしない）。
- 描写の注意: 闇落ちの貧困や、トクリュウの受け子と、人物のルーツ（混血・移民）を、結びつけない。犯罪や貧困を、特定のルーツの属性として描かない。

## 登場人物

| 人物 | 設定 |
|---|---|
| 主人公 | 性別は開始時にプレイヤーが選ぶ。**必ず車椅子の側**（幼稚園の事故で、かばって障害を負った）。名前や性格は男女で共通 |
| 幼馴染（相手） | 主人公と異性の、**立てる側**。事故でかばわれた。結婚相手（当面は一択） |
| 同性の友達 | 主人公と同性。貧困から闇落ちし、少年院へ。奪回の対象 |
| 異性の友達 | 主人公と異性。少年編で引っ越し、**青年編で再会**。就職していて、垢抜けている。主人公は一度は幼馴染より魅力的に感じる |
| 不良 | 少年編の敵。闇落ちする友達が巻き込まれる集団の伏線 |
| トクリュウ | 匿名・流動型犯罪グループ。**竜の当て字**の仮想的なモンスターの組織。本部は外国（実在の国名は出さない） |

男女の違いは、立ち絵・呼称・一人称などの**属性**だけ。脚本は「主人公」「相手」の二人分だけ書く。

| 編 | 出来事 | パーティ |

## 事故（物語の発火点）

- 幼稚園の劇は、無事に最後までやり遂げる。事故は劇のあとに、**水辺**で起きる。
- 幼稚園の責任ではなく、ありふれた交通事故でもない。
- **普通に溺れかけたのではなく、水に近づいたせいで、水の召喚獣に襲われる。** 水の召喚獣は、**日本の古来の神のような、妖怪のような存在**にする（候補: 河童、水虎、蛟（みずち）、水神、龍神など。具体は未決）。
- 片方がもう片方を**善意でかばい**、かばった側が障害を負い、車椅子になる。
- 水辺に子供を近づけないための民間伝承（河童が子供を水に引き込む、など）は、古来の水難への警鐘そのもの。この事故は、その伝承の現代版として、**水難への警鐘**にもなる。
- 場面は再現しない。暗転して時間が経ち、退院後の場面に飛ぶ。
- 水の召喚獣は、のちに召喚獣の要素を入れるときに、物語と結びつく（下の「召喚獣」）。

## 召喚獣（後で入れる）

- FF の召喚獣の要素を、あとで入れる。
- 召喚獣は、**日本の古来の神のような、妖怪のような存在**にする。事故の水の召喚獣は、その一つ。
- 召喚獣を「現実の言い替え」（困ったときに呼べる親や祖父母）として扱うか、神や妖怪として扱うかは、設計で決める。両方を重ねる案もある。
- トクリュウの「竜」（FF6 の八竜にかけた当て字）と、水の龍神などの関係を持たせるかは、未決。
- エンジン側の要件は name-name の Issue（召喚の仕組み、演出）。

## 主題

- 車椅子の人に立てる側が告白すると謝罪のようになり、車椅子の側から告白すると断れない脅迫のようになる。**そう考えさせないほどの愛を書く**のがテーマ。
- 同情と愛の違い。主人公は同情される側として育ったので、同情の形をした好意に敏感。友達も貧困ゆえに同情される側。奪回の鍵は、同じ立場を知る主人公の言葉。
- 他の選択肢（垢抜けた再会者）に一度は惹かれた上で、幼馴染を選ぶ。選んだものとしての愛。
- 二人のプロポーズの言葉は、「君の隣に座らせて」を意味する英語（案: **Let me sit by you.**）。題名への応答。

## 勝敗の形

- 敵はトクリュウ組織。戦って倒す。
- 友達は「はなす」ことで取り戻す（戦わずに心を動かす）。
- 少年院や警察署を襲撃することはない。外国の本部を襲撃する場面でも、公的機関が別ルートで動いていることを描く。

## 描写の方針と確認事項

- 水難事故、脊髄損傷とリハビリ、少年院と更生の流れ、闇バイトの勧誘と受け子の実態は、**専門家や当事者の視点で確認する**（#2 を参照）。
- 事故の場面は再現せず、暗転して時間が経つ形にする。
- 受け子の被害者（多くは高齢者）の存在を、物語が無視しない。
- 水難と闇バイトの二つの警鐘を物語に含める。ただし説教にしない。
- 外国は実在の国名を出さない。
- 幼馴染を当て馬にしない。再会した友達も、主人公を揺らす装置にしない。

## 結婚相手

- 当面は**幼馴染の一択**。
- 将来、友達2人（男女）を結婚相手の候補に足し、DQ5 式の分岐にする。結婚相手は固定のキャラではなく「相手」スロットで持つ（#739）。
- 幼馴染以外を選ぶ分岐を作ると、幼馴染は結婚しない友達の位置に回る。主人公二人の構造とぶつかる点なので、拡張時に設計で決める。
- 再会した友達に一度惹かれる場面は、今は選択肢にせず、内心と演出として書く。
