# 刃（刀）候補調査: 有名な刀の実在リスト

調査日: 2026-10-15 / 調査担当: Claude（読み取り調査のみ。最終決定は kako-jun）

## 0. 使い方・凡例

- 本書は sit-by-me に出す「有名な刀」の候補と、4人への割り当て案。**割り当ては案**。
- 既存作品（刀剣乱舞など）の擬人化・設定・固有名は流用していない。刀そのものの史実のみ。
- 確度の印:
  - ◎ = 文化庁「文化遺産オンライン」等の一次情報を直接取得して確認
  - ○ = Wikipedia（出典付き記事）で確認し、補助資料と突き合わせた。指定・所蔵は公的DBで再確認が望ましい
  - △ = 二次資料のみ、または資料間で食い違いあり
- 「伝承」は史実として確認されていない話。「未確認」は今回確認できなかった事項（推測で埋めていない）。
- 注意印: 【注】= 採用に注意（現存不明・損傷・個人蔵・御物・宗教上など）。詳細は第4章。
- 一次情報の取得制限: 文化庁 国指定文化財等データベースと ColBase は動的ページのため直接取得できなかった項目が多い。◎は文化遺産オンラインの詳細ページを取得できたもの（童子切安綱・三日月宗近・へし切長谷部）のみ。他は○/△。
- 時代の枠: 古代 / 中世（平安末〜南北朝）/ 戦国 / 江戸（幕末を含む）。幕末を独立の枠にする案は第3章末に記載。

## 2. 個性の素（実在の特徴に由来）まとめ

- 古代: 銘文・祭祀・星・枝分かれ・大陸渡来・直刀
- 中世: 優美・短く堅牢・長大で軽い・魔除け/守りの伝承・華やかな刃文
- 戦国: 身幅広く圧し切る・長大・脇差で軽い・焼身・戦利品・妖刀の俗説
- 江戸: 切れ味・波の刃文・実用の研究・強靭・実戦

数値は書かない。

## 3. 割り当て案（4人×5本=20本）

時代の法則: ペー子=古代 / オトン=中世 / ナム=戦国 / シャー=江戸（幕末を含む）。

### ペー子（古代: 銘文を読み解く・診る・分析する）
1. 七支刀: 枝刃と銘文の謎。医者の娘が「読む・診る」姿勢に合う
2. 金錯銘鉄剣（稲荷山）: 115字の系譜。分析型の基本の刃
3. 銀象嵌銘大刀（江田船山）: 75字。別の銘文との比較で学ぶ
4. 中平銘鉄刀（東大寺山）: 百練・星宿。大陸渡来の刃を調べる
5. 七星剣: 北斗七星の象嵌。星と護り（聖徳太子の佩刀は伝承）

補欠: 丙子椒林剣（国宝実物か模造か未確定）、小烏丸（御物）

### オトン（中世: そばにいる・守る）
1. 大典太光世: 短めで堅牢。金沢・前田家の重宝。病を除いた伝承
2. 数珠丸恒次: 日蓮の守り刀の伝承（寺宝に注意）
3. ソハヤノツルキ: 子孫を護るため納めたと伝わる（伝承）
4. 三日月宗近: 優美で静かな佇まい。守りの構え向き
5. 鬼丸国綱: 魔除けの伝承（御物に注意）

補欠: 童子切安綱、石切丸、謙信景光（戦国表から。短い守り刀）

### ナム（戦国: 元気・速攻・連撃）
1. へし切長谷部: 磨り上げで刃長64.8cmと取り回しがよく、一太刀で圧し切る
2. 骨喰藤四郎: 刃長58.7cmの薙刀直し。軽い
3. 義元左文字: 刃長66.9cm。桶狭間の戦利品（伝承）で勢いがある
4. 山姥切国広: 長大で反り強く大鋒。連撃より一撃の伸びがある別軸の個性
5. 村正: 切れ味。妖刀は俗説と明記して使う

補欠: 大般若長光、燭台切光忠（焼損）、同田貫（シャーに回す案も）

### シャー（江戸・幕末: 体力・耐える・突破する）
1. 長曽祢虎徹: 切れ味と頑丈さの評価が高い名工
2. 源清麿: 荒試しで強靭さを示した刀（兄の作との関係に注意）
3. 水心子正秀: 実用・武用の研究者。丈夫な鍛えの追究
4. 和泉守兼定: 実戦を戦い抜いた幕末の刀
5. 加州清光: 金沢（加賀）の刀工系統。個別名物は要特定

補欠: 津田助広、同田貫（戦国枠だがシャーの「耐える」に近い）

### 4人の枠に関する提案
- 幕末を独立の第5の時代にする案: 和泉守兼定・加州清光を「幕末」にまとめ、江戸前期（虎徹・助広）と分ける。ただし4人に4時代なので、現行案は江戸に幕末を含める。
- 戦国枠が最も候補豊富。古代枠は「刀でなく遺物」が多いので、ペー子の5本は実用武器というより「調べる刃」になる。この性質を意図して採用するか要判断。
