# 素材の方針

## 実写と生成の線引き

| 対象 | 方法 |
|---|---|
| 背景 | 実写の写真 |
| 車、自販機、段ボールの小道具、武器などの**物** | 実際にカメラで撮った写真を切り抜く |
| **人物**（主人公、友達、不良、トクリュウの構成員） | 生成画像（肖像権のため）。頭身は普通の人間。**イラスト調**で揃える |
| 海外の舞台、少年院などの撮影できない場所 | 生成画像、またはライセンスのある素材 |

人物を実写寄りに生成すると、実在の人物に見えてしまう。**必ずイラスト調**にする。

## アクスタ統一

- すべてのスプライトに同じ処理: 輪郭の外側に**透明な余白**を取り、その外周に**枠線**を引く（白で塗らない。余白越しに背景が見える）、反射ハイライト、黒い円形台座、床の接地影。
- 車椅子に座った人物も同じ（アクスタは「立つ板」）。
- 実写背景でも境界が読めることが目的。

## 実写素材の取り扱い

- ナンバープレート、通行人、表札、窓の中などの個人情報は、処理してからコミットする。
- 処理が済んでいない実写素材は、このリポにコミットしない。
- **撮影は今できない。** 試作の間は生成画像で仮置きし、あとで実写に差し替える。画像は必ず**パスで指す**形にして、差し替えをファイル置換だけで済ませる。
- 冒頭の劇の敵は、段ボールで手作りしたドラゴンを撮影する予定（手作り感が欲しい）。

## 生成のパイプライン

- 画像生成は、既存の方式（参照画像つきの imagegen）を使う。
- キャラクターは同一性を保つため、参照画像を使う。
- 年齢段階（幼稚園、少年、青年…）と、事故の前後の立ち絵を作る。
- 表情の差分は、眉、頬、目、口を具体的に書き分けて指定する。

## サンプル

`docs/samples/` に方向確認用の生成サンプルがある。採用画像ではない。

## マスター画像とポーズ一式（タイル生成）

- 各キャラは、まず**マスター画像**を作る。マスターは、同一性の基準として、以後の生成の参照にする。
- マスターが決まったら、サイドビューやフィールドで必要な**ポーズ一式を、タイル状の1枚にまとめて生成**する（同時に作ったほうが同一性を保てる）。
- 一覧（案）: 待機、武器を振る、被ダメージ、倒れる、詠唱（ジョジョ立ちのような過剰なポーズ）、必殺技、勝利、フィールドの各方向（上下左右）。
- 実際に使う立ち絵は、背景を透過した切り抜き（PNG）にする。タイルから切り出し、背景を抜く。

### 登場人物（仮名。既定名は案で、story.md の「名前」を参照。見た目は仮のテンプレ絵で、差し替える）

| 仮名 | 設定 |
|---|---|
| 男A | 短い黒髪の少年。赤と白。主人公（男）／幼馴染（主人公が女のとき） |
| 女B | 栗色の髪、ピンクの花の髪飾り。ピンクとクリーム。主人公（女）／幼馴染（主人公が男のとき） |
| 男C | 大柄、明るい茶色のくせ毛。緑とグレー。 |
| 女D | 黒髪のボブ、丸眼鏡。青とラベンダー。 |

C と D は、主人公の性別によって、同性の友達と異性の友達の役が入れ替わる。どちらも、闇落ち・引っ越し・再会の両方の姿を持つので、画風を揃えておく。

### 作成済みのマスター（`assets/characters/masters/`）

- `cast-growth-sheet.png`: 4人 × 3段階（幼稚園・小学生・青年）の正面立ち絵を1枚に。同じ人物が行をまたいで同じ人物に見える。
- `cast-wheelchair-sheet.png`: 男A・女B の、小学生と青年の車椅子姿。
- `boy-a-` / `girl-b-` / `boy-c-` / `girl-d-kindergarten-master.png`: 幼稚園の三面図（正面・横・背面）。
- 生成した画像の大きさは、依頼した大きさ（3840x2160）より小さい（1672x941 前後）。高解像度が必要なものは、あとで個別に作り直す。

## キャラクターデザインは仮（後で差し替える）

- いまのマスター画像は、**仮のテンプレート絵**（AI が出す定番の見た目）。サンプルや試作の確認用で、**後で差し替える**。
- 差し替えるときは、**キャラごとの特徴**を入れて、テンプレ感を消す。特徴づけの方向（案）:
  - エクステを付けて、髪の一部だけ色が違う
  - 眼鏡
  - カラフルなバンダナ
  - 開放的な服装を好む
  - 三白眼
  - 髪が白い
- 世界観は少し未来の日本で、混血や移民が進み、服装や髪の自由度が高い（story.md）。人物は全員を「日本人の見た目」に固定せず、髪色・肌・顔立ち・服装の幅を持たせる。
- 特徴は、年齢段階（幼稚園・小学生・青年）をまたいで引き継ぐ。成長しても同じ人物と分かること。
- どの特徴を誰に付けるかは、未決（sit-by-me のキャラデザインの Issue）。
- サンプル用の切り抜き画像は、**足元に余白を残さないタイトな切り抜き**にする（アクスタの台座の中心に、スプライトの外接矩形を合わせるため。足元に透明な余白があると、台座から浮いて見える）。

## 体内ダンジョンの敵（今どきのウイルスなど）

- 実在の病原体の名前を敵の名前に使う（story.md「ダンジョン」）。見た目は、人物ではないので生成画像でもよいが、肖像権の問題は無い。実在の病原体の見た目（電子顕微鏡像など）を参照する場合は、元の画像の権利を確認する。

## 葬送の場面（葬式・火葬場）

- 火葬場、斎場など、撮影できない場所と、葬儀の場面は、生成画像で描く（実写の撮影は、場所と遺族への配慮から行わない）。
- 葬送の作法（通夜、告別式、火葬、骨上げなど）は、地域や宗派で違うので、専門家の確認を受ける。

## 地震の前と後の街

- 少年編の地震（story.md「地震」）で、街がほぼ滅ぶ。背景は、**地震の前の街（実写）**と、**地震の後の街（生成画像）**を用意する。
- 被災地の実写の撮影は行わない（被災者への配慮）。
