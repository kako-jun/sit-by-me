# K県の人物・町・敵 — アートディレクション

## 舞台

- 舞台は、金沢をセルフパロディ化した架空の**金沢県（K県）金沢市**。現実の金沢をそのまま複製せず、少し雪深い日本海側の地方都市として組み直す。
- 冬だけで完結する RPG にする。暗い曇天、積雪、融雪水、雪で傷んだ道路を全編の基調に置く。夏の場面は当面作らない。
- 生活圏の最初の背景セットは **寺町 → 鱗町 → 思案橋 → 菊川**。寺社、石段、寺の塀、墓地、古い住宅、空き地、用水、古い商店と現代の店を同じ町の層として置く。
- 中盤には**香林坊**を通る。K県で一番の街として、店が連なる繁華街・交差点・地下へ下りる入口を置き、寺町側の生活圏とは別の都市の層にする。
- 雪国の共通語彙は、消雪パイプ、赤白スノーポール、雪囲い、雁木、除雪の雪山、融雪水、錆びたトタン、湿気で黒ずんだ木壁。
- 海へは**浅野川鉄道**で内灘へ向かう。朽ちたローカル車両と小駅は移動の節目であり、「魔列車」的なイマジナリー脅威が重なる場面でもある。ただし、現実の車両・駅を破壊する話にはしない。
- 内灘の砂丘・海は、試射場計画とそれに抗した人々の歴史を下敷きにする。史実をそのまま娯楽化せず、K県独自の過去として再構成し、住民の暮らしと抵抗を背景に残す。
- 内灘には**風の召喚獣**を置く。砂丘の風紋を削り、顔を叩く「殺意の風」として現れる。風には米軍の残した砲弾の欠片の気配も混ざった、殺意の強風にする（2026-10-14）。魔石は試射場の砂と結びつくK県内のフィクションの石／石片であり、実在の砲弾・不発弾を拾う話にはしない。米軍の影はこの内灘の記憶だけに限定する。
- 海辺には、かつての**粟崎遊園**を思わせる、失われたレトロ遊園地の像を重ねる。営業中の施設を壊すのではなく、駅の窓・砂浜・古写真から想像が立ち上がる場所にする。
- 卯辰山は、昔あった**サニーランド**の名残をたどる山上ダンジョンにする。壊れた案内板、雪をかぶった展望設備、使われない遊具の記憶を道標に、頂上へ登る動機を作る。
- 卯辰山・サニーランド跡には、少年編前半の**氷の召喚獣**を置く。雪に埋もれた遊具と凍った展望設備を、止まった時間のように見せる。
- 後半は、茶屋街の茶室、能登の救援地点、**K空港**へつながる。生活圏は金沢と能登で完結させ、金沢より南の都市・地名・方向は描かない。K空港の所在地・方角も明かさず、県外へ出るための境界としてのみ置く。都会へ移って解決する物語にはしない。
- トクリュウ救出地点は、砂漠に立つ無国籍の密集垂直都市。ダンジョンの恐怖は、キョンシー的な跳び人形、波紋のある刃、包帯の人形、暗い土の塚、異様な編み飾り、仮面など、昭和の映画・怪奇本・ニュースで主人公が混ぜてしまった「異国への誤像」として出す。実在の国・民族・宗教・工芸・葬送習慣を敵にしない。普通に暮らす住民や市場、住居の明かりを対照に置く。
- 終盤の場面パックは兼六園と金沢城を下敷きにした庭園・城跡。実在の金沢城に天守閣がないことを反転させ、最終夜だけイマジナリーな天守閣が現れる。現実の JPCZ による冬の雲を、主人公が運命の像として見た**日本海寒帯気団収束体**と空中で戦う。戦闘名は漢字だけの**日本海寒帯気団収束体**とする。
- 城を進む護衛敵は、子供の物の恐怖ではなく、大人になって古い白黒映画やニュース越しに知るこの世への怒りと恐怖の像にする。白黒の怖い侍は、古い時代劇フィルムから滲み出したような、乾いた画質・強い陰影・無言さを持つ像にする。インフレは値札・数字・生活を圧迫する重み、外国での戦争は遠いニュース画面・煙・警報、核兵器は白い閃光・警報・圧力・影として出す。国・軍・市民・実在兵器を敵にしない。
- 背景は、実写の写真そのものに似せず、**デフォルメされたジオラマ**と分かる質感とサイズ感にする（2026-10-14 kako-jun。ファンタジアンの手法）。木は鉄道模型の木のように明らかに模型っぽくし、質感はプラスチックや土っぽく、粒子を荒くする。雪は、粉や綿で再現したような質感にする。その上にアクスタを立てる見立てにして、縮尺の違和感を解消する。構図は、なるべく奥行きが感じられるものに仕上げる（手前・中景・奥の層をはっきり作り、道が奥へ伸びる。2026-10-14 kako-jun）。
- 背景はタイルを無限に継ぎ足さない。場所ごとに、全景・広い道路・狭い道・接続画を同じカメラ、光、反復物で一度に作る。視点は真上でなく、高めの斜め見下ろし。フィールドは固定の一枚絵で、スクロールしない。絵の端で次の絵に切り替わる（2026-10-14）。

## 人物素材

- **4人とも日本人（東アジア）の顔立ち**にする。髪色は非現実でよいが、金髪の全面指定は白人の顔に寄るので、メッシュなど部分で入れる。
- **テーマ色は年齢とともに落ち着かせる**（2026-10-14 kako-jun）。ナム（ヒロイン）はピンクだけでなく青系もテーマ色で、大人になるほど青寄りの落ち着いた印象へ。**長いマフラーはナムの特徴**として、小学生から大人まで身につける。オトン（主人公）の赤も、落ち着いた赤や白へ移っていく。落ち着かせるのは服などの色で、**髪の色は派手なまま**。
- **大きな帽子はこのゲームの特徴**。幼稚園期のニット帽は4人とも大きめ。学生以上も大きな帽子をかぶってよい。デザインは年齢段階ごとに変える（幼稚園のニット帽と同じものにしない）（2026-10-14 kako-jun）。
- **決めポーズ**: 幼稚園児でもジョジョ立ちのような決めポーズをしてよい。同じキャラは大人になっても同じ決めポーズをする。
- 確定マスター: `assets/characters/masters/{otton,nam,shah,peiko}-kindergarten.png`。戦闘ポーズは `assets/characters/poses/{name}-{idle,ready,step,slash,hurt,down,cast,special,victory}.png`（お遊戯会の園服版は `{name}-uniform-{pose}.png`）（左向き・背景透過。元の 3x3 グリッドは `poses/raw/`。クロマキー背景で生成し、各コマの体にはみ出した刃・手足を付けて切り出す）。
- 採用方向は、実在人物を参照しない**実写寄りの生成キャラクター**。AI の定番アニメ顔、既存人物への類似、実在人物の肖像は避ける。
- 鉛筆線と透明水彩による非テンプレ絵は比較用に試したが、採用方向ではない。
- まず同一人物性を固定するマスター三面図を作り、決定後にポーズ一式をタイル状に生成する。
- 幼稚園期は、茶系の園服と、積雪時の子供用スノーボードウェアを両方作る。水色のスモックは採用しない。**お遊戯会の劇（冒頭の戦闘）は園服**で戦う。
- 小学生から上の学生期は**制服**を着る（北陸は小学生も制服）。小学生は男女とも**ブレザー**（女子はスカート）。中学から上は、男子（オトン・シャー）が**ブレザー**、女子（ナム・ペー子）が**セーラー服**（2026-10-14 kako-jun 決定。小学校にセーラー服はない）。一般的なデザインそのままにせず、**ジョジョのような変形学生服**も許される自由な時代として、各人が自分流に着崩し・改造する（案は生成で数種並べて選ぶ）。スカートの下にスパッツ・レギンスなどのズボンは履かせない。防寒着と、祭り用の浴衣差分も用意する。
- 壮年編の主人公は、車椅子のまま雪よけの羽織・防寒長着をまとい、子供たちを率いる非常に強い親の姿にする。
- 事故後の主人公は、戦闘もフィールドも**車椅子のまま**（想像の層でも立たせない。2026-10-14 kako-jun）。戦闘ポーズ・歩き（移動）も車椅子で作る。
- 事故後の主人公（オトン／ナム）の車椅子姿では、**脚の切断面は見せない**。膝掛けやコートで太ももから膝を覆う（2026-10-14 kako-jun）。
- 親世代は、子供時代の視点では固有の顔をはっきり描かない。子供から見上げる**顔の見えない巨人**として、腰から下、手、背中、靴、冬のコート、足音、声で存在を示す。親を目立たせず、視点の中心は四人の子供に置く。

- 配偶者の死後、相手が得たアビリティは主人公へ全て統合する。これは能力を奪う表現ではなく、二人で生きた時間が主人公の戦いに残る表現。

## イマジナリー敵

- 現実にある物が、主人公の恐怖や想像で敵の姿に重なる。実際には機械や物を壊していない。
- 敵候補は恐怖の種類で増やす。

  | 棚 | 候補 |
  |---|---|
  | 圧倒的な機械・物 | ロードローラー、大型ドリル、使用者のいない銃 |
  | 交通と騒音 | 乱暴な自転車・車・大音量のバイク。運転者は描かない |
  | 都市の巨大物 | 香林坊の大型立体看板のようなお神輿型中ボス |
  | 暗い開口部 | 蓋の開いたマンホール |
  | 錯視 | 夜の森で悪魔に見える葉・枝、顔に見える壁の染み |
  | 展示物・玩具 | 迫って戦場を狭める防火シャッター、ショーウィンドウのマネキン、子供部屋・古道具店・祭りの飾りの人形 |
  | 大人・子供向けの恐怖メディア | 目隠しされた大人向けの本、架空のホラーDVD、怪奇本、怪人・ひとさらい風の絵本、笑い袋 |
  | 知識の恐怖 | 分厚い百科事典・難解な勉強の本。ページがめくれるたびに難問や重みが増す |
  | 医療・理科室の不気味さ | 人体模型、ホルマリン漬けのびん、骨格模型、注射器、歯科ドリル |
  | 水辺の生物 | 巨体・長い触腕・墨を使うイカ、吸い付き・からみつき・多腕を使うタコ、群れと毒棘のゴンズイ、膨らみと毒のフグ |
  | 毒と尖り | 病原体、毒キノコ、釘、割れたガラス、金網、有刺鉄線、氷柱、ウニ |
  | におい・空気 | タバコの煙と灰、酒の強いアルコール臭と揺れる液面 |
  | 崩壊・落下 | 落ちてきそうなシャンデリア、割れた窓、破れた障子、割れた酒瓶 |
  | 回転する刃（風） | プロペラ、扇風機・換気扇の羽根。体が切断されそうな恐怖から風を起こす（2026-10-14） |
  | 凍った足元（氷） | 凍った水たまり。滑る・割れて落ちる恐怖から氷を使う（2026-10-14） |
  | 火事の原因（火） | 石油ストーブ、ライター、古いたこ足配線など、火事の原因になるもの。実際の火災を描かず、物それ自体が恐怖の像（2026-10-14） |

- 敵は明らかに怖くないものを入れない。属性の穴を埋めるときも、恐怖の根拠がある物だけを採る（雪だるま、ドライヤー、提灯のような、怖くない物は不採用）（2026-10-14）。
- 人間を敵にしない。銃は使用者を置かず、物それ自体が恐怖の像となる。葉・枝・染みは、近寄ればただの自然物・汚れである。マネキンと人形も展示物・玩具のままにする。指名手配風ポスターや誘拐を思わせる道路標識は、実在人物・氏名・事件を使わない架空の図像にする。
- 昆虫・病原菌は、恐怖を残しても嫌悪感を強めすぎない。ゴキブリ、腐敗、体液、内臓、寄生の露出は扱わず、戦闘画面で輪郭が読める造形にする。
- 敵素材も背景から分離し、アクスタの枠・台座・影は描画時に後がけする。
- サイドビュー戦闘では敵は左側から右の主人公側を向く。マスターは右向きで生成し、必要時だけ描画側で左右反転する。そのため読める文字・ロゴ・左右で意味が変わる意匠を敵素材に入れない。**召喚獣も元は敵素材として同じ右向きマスターを作り、味方として右側へ呼ぶ場面は描画側で左右反転して左を向かせる。**

## 装備と育成

- 装備は2枠だけ。**スマホ**が全員共通の刀の核（戦闘ジョブ・能動アプリ・解放）、**タブレット**が防御・解析・フィールドジョブ・常時効果アプリを担う。
- 本体の収集ではなく、何をインストールしたかでビルドを変える。実在アプリ名は使わない。
- 戦闘後には必ず AP を得て、装着中のアプリが習得・強化・派生する。戦闘のたびに目に見えるメリットを置く。
- 味方の武器は**刀に統一**する。日本刀は第三の装備品にはしない。スマホの能動アプリが生む、実体とも想像とも読める「想像の刃」として現れる。ヨーヨーなど他の日用品武器には広げない。銃は敵側の恐怖の像であり、味方の装備にしない。
- 想像の刃は、固有名を呼んで解放する第一段階と、戦場ルールを変える最終段階を持つ。既存作品の固有用語は使わず、4人の素質と物語に沿う独自の呼称・能力にする。
- 攻撃・回復・補助はすべて**魔法**に統一する。敵の技を受け、戦闘終了時に自動でラーニングして初めて詠唱できる。回復も敵の自己修復や保護から学ぶ。想像の刃は人物固有、魔法は敵由来の共有能力として明確に分ける。
- 属性はFF5／6時代の直感を基準にする。各属性の魔法は一つだけとし、炎の下位・中位・上位のような使われない重複を置かない。魔法・アイテムは全て、終盤まで固有の使いどころを持たせる。
- 召喚は、スマホ／タブレットと無関係な**魔石**で扱う。魔石はその場所で拾ってポケットに入れる石であり、思い入れが生まれたときだけ、イマジナリーな召喚獣が現れる。取得は6属性ともストーリー上の通過点で必ず得る形に変更（2026-10-14）。聖地巡礼やごっこ遊びのように場所の記憶を持ち歩く要素にする。属性名ではなく日本海・卯辰山・川から来た火のような、場所と物に結びついた具体的な召喚獣にする。魔法・想像の刃とは別系統にする。
- 召喚獣も戦闘上は一つの属性を持つが、各属性につき一体だけにする。
- 召喚獣も、敵と同じく実写っぽい生成画像を基礎にする。
- 火の召喚獣は、川霧の中を流れる青白い火の群れが**ネコ**の輪郭を取り、熱い心（怒り・混乱）に反応して赤く変わる姿にする（2026-10-14）。造形は、四つん這いで足が車輪になったネコ（FF4のカイナッツォのような四足の構えと、火車の連想）で進める。
- ラストバトル（二周目の金沢駅の鼓門前）だけの隠しの召喚獣は、長子が使う。建前上は聖属性で、イマジナリー鼓門がアレクサンダーのようにビームを使う（鼓門と形が似ているため）。6属性の外に置く一回きりの特例（2026-10-14）。最後の攻撃はラスボス2体へ9999ダメージで、これが妻側を折れさせる決着の引き金になる。
- 土の召喚獣は、海外の砂漠の密集垂直都市の建物そのものが獣だったもの。国名は出さない。トクリュウから逃げるときのボスとして戦い、倒して得る（2026-10-14）。地震の召喚獣（タイタンのオマージュ）は別枠のままで、土とは同一にしない。
- 日本海の召喚獣は、暴風雨、荒波、灰色の波の花で作る。青く美しい海や竜にはしない。竜モチーフは、ラスボスの雲核を断った後に現れる雷竜だけへ限定する。雷竜は雲が消えて現れるのでなく、帯状雲・雲核・氷・閃光が複雑に絡みついたまま輪郭を取り、顔は雲と雷に浮くドクロにする。
- 召喚獣は人生の時代にも一体ずつ結び付ける。水（幼稚園編・能登）、氷（少年編前半・卯辰山）、風（少年編後半・内灘）、火（青年編前・川から流れ着く魔石）、土（青年編救出・海外砂漠）、雷（壮年編最終・金沢城）の順に置く。火の魔石は白山の火の気配を帯び、悩み・争い・混乱の中にある熱い心へ反応して芽生える。雷だけは一周目ではラスボスであり、二周目のみ最強の召喚として使える。
