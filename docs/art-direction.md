# K県の人物・町・敵 — アートディレクション

## 舞台

- 舞台は、金沢をセルフパロディ化した架空の**金沢県（K県）金沢市**。現実の金沢をそのまま複製せず、少し雪深い日本海側の地方都市として組み直す。
- 冬だけで完結する RPG にする。暗い曇天、積雪、融雪水、雪で傷んだ道路を全編の基調に置く。夏の場面は当面作らない。
- 寺町の背景は、何もない通路的な背景は**せいぜい1つだけ**にして、残りは場所に個性を持たせる（幼稚園、銭湯、坂をのぼった場所など。2026-10-14 kako-jun）。通路的な背景は、広い道路の1枚（承認済みのジオラマ）。すでに作った接続画（斜めの道と石橋）と狭い道（縦の路地と山門）は、捨てずに、寺町のマップのボリュームを増やすために使う（2026-10-14 kako-jun）。
- 生活圏の最初の背景セットは **寺町 → 鱗町 → 思案橋 → 菊川**。寺社、石段、寺の塀、墓地、古い住宅、空き地、用水、古い商店と現代の店を同じ町の層として置く。
- 中盤には**香林坊**を通る。K県で一番の街として、店が連なる繁華街・交差点・地下へ下りる入口を置き、寺町側の生活圏とは別の都市の層にする。
- 雪国の共通語彙は、消雪パイプ、赤白スノーポール、雪囲い、雁木、除雪の雪山、融雪水、錆びたトタン、湿気で黒ずんだ木壁。
- 海へは**内灘線(架空)**で内灘へ向かう。朽ちたローカル車両と小駅は移動の節目であり、「魔列車」的なイマジナリー脅威が重なる場面でもある。ただし、現実の車両・駅を破壊する話にはしない。
- 内灘の砂丘・海は、試射場計画とそれに抗した人々の歴史を下敷きにする。史実をそのまま娯楽化せず、K県独自の過去として再構成し、住民の暮らしと抵抗を背景に残す。
- 内灘には**風の召喚獣**を置く。砂丘の風紋を削り、顔を叩く「殺意の風」として現れる。風には米軍の残した砲弾の欠片の気配も混ざった、殺意の強風にする（2026-10-14）。魔石は試射場の砂と結びつくK県内のフィクションの石／石片であり、実在の砲弾・不発弾を拾う話にはしない。米軍の影はこの内灘の記憶だけに限定する。
- **風の召喚獣の訂正（kako-jun 2026-10-14）: 土の要素を入れない（砂の渦・風紋・砂丘・砂色は不可）。砲弾や尖った、霧を裂く風のイメージ。生き物のモチーフは飛んでいる鳥。** 内灘の海風・冬の霧の場面性は保つ。上の「風紋を削り」は破棄。素材は 旧風召喚獣案（現存画像なし。現行S003はassets/images/summons/S003.webp）。
- **風の召喚獣の再訂正（kako-jun 2026-10-14）: 鳥そのままにしない。風そのものの形が主役で、鳥は暗示。** 素材は uchinada-wind.png（3案から C 案の嘴状に尖る螺旋の気流を採用。kako-jun 2026-10-14）。
- **風の召喚獣の変身形（kako-jun 2026-10-20）**: 上の「鳥は暗示」は基本形についての指定。変身タイプであり、別途、鳥形の絵を作る。変身形は刃物のような翼、鋭く長いくちばし、細長い身体を持つ。FF4のバルバリシアのオマージュ。
- 海辺には、かつての**粟崎遊園**を思わせる、失われたレトロ遊園地の像を重ねる。営業中の施設を壊すのではなく、駅の窓・砂浜・古写真から想像が立ち上がる場所にする。
- 卯辰山は、昔あった**サニーランド**の名残をたどる山上ダンジョンにする。壊れた案内板、雪をかぶった展望設備、使われない遊具の記憶を道標に、頂上へ登る。登る理由は「サニーランドの廃墟で探検しよう」（子供たちの廃墟探検。2026-10-14 kako-jun）。
- 卯辰山・サニーランド跡には、少年編前半の**氷の召喚獣**を置く。雪に埋もれた遊具と凍った展望設備を、止まった時間のように見せる。
- **事実の訂正（2026-10-14 kako-jun）: 卯辰山のサニーランドは屋内施設で、観覧車はない。** あったもの: 大きな白いコンクリートのシャチホコ、屋内水族館と狭い動物園、昭和のゲームセンター、ござの敷かれた和室、円形の空間に入っていくエントランス。背景はそれらの廃墟（屋内）として作る。屋外の山道（うねる山道は正解）は、山を登る道として別に使える。上の「遊具・展望設備」の記述は、この事実に合わせて読み替える。
- 後半は、茶屋街の茶室、能登の救援地点、**K空港**へつながる。生活圏は金沢と能登で完結させ、金沢より南の都市・地名・方向は描かない。K空港の所在地・方角も明かさず、県外へ出るための境界としてのみ置く。都会へ移って解決する物語にはしない。
- トクリュウ救出地点は、砂漠に立つ無国籍の密集垂直都市。ダンジョンの恐怖は、キョンシー的な跳び人形、波紋のある刃、包帯の人形、暗い土の塚、異様な編み飾り、仮面など、昭和の映画・怪奇本・ニュースで主人公が混ぜてしまった「異国への誤像」として出す。実在の国・民族・宗教・工芸・葬送習慣を敵にしない。普通に暮らす住民や市場、住居の明かりを対照に置く。
- 終盤の場面パックは兼六園と金沢城を下敷きにした庭園・城跡。**兼六園は夕方、金沢城は夜**として、石川橋を越えるときに終盤の高揚を光の移り変わりで受け渡す。実在の金沢城に天守閣がないことを反転させ、最終夜だけイマジナリーな天守閣が現れる。現実の JPCZ による冬の雲を、主人公が運命の像として見た**日本海寒帯気団収束体**と空中で戦う。戦闘名は漢字だけの**日本海寒帯気団収束体**とする。
- **金沢城MAPの建物美術（kako-jun 2026-10-21）**: 石川門・橋爪門・櫓・長屋・イマジナリー天守など、城の建物はマッチ棒工作で作った模型として表現する。城MAPは夜景にし、建物や壁に小さなLEDの点光源を仕込む、または壁面を照らす間接照明で光を見せる。光は模型の工作感を残した暖かい明かりにし、実写風・写実的な夜景にはしない。一般の建物に使う厚紙・段ボール等の共通材料指定より、この城限定のマッチ棒工作を優先する。金沢城MAPの範囲と接続は `map-specifications.md` の CST-01〜CST-10 を参照。
- 城を進む護衛敵は、子供の物の恐怖ではなく、大人になって古い白黒映画やニュース越しに知るこの世への怒りと恐怖の像にする。白黒の怖い侍は、古い時代劇フィルムから滲み出したような、乾いた画質・強い陰影・無言さを持つ像にする。インフレはデジタル数字に加えて飛んでいく紙幣とボロボロになった靴、外国での戦争は第一次世界大戦期を思わせる無標識の複葉機シルエットと警戒サイレンの赤、核兵器・放射能の恐怖は現代彫刻のようなニュークリア記号とコンプトン散乱光として出す。M205にサイレンや黒い影は使わない。国・軍・市民・実在兵器を敵にしない。
  - 整合の注記（2026-10-22、#123。旧文は残す）: 金沢城の三闘神級 M014 は WW1・WW2・WW3 の戦争の擬人化（kako-jun 決定 2026-10-22）。WW1 はガスマスク・複葉戦闘機・毒ガスをまとい低く身構える。WW2 は爆撃機・戦車の意匠を持つ女神で、片足を上げて舞う。WW3 は核ミサイル・無人機・電子戦をまとい空中で身をひねる。三体は人型で別々のポーズとし、国旗や実在軍の徽章は使わない。ノストラダムラー（M022 案。ノストラダムスがモデルで肖像画から飛び出るポーズ）は**人間の姿のまま（kako-jun 決定 2026-10-22。下の「人間を敵にしない」の決定済みの例外。M002 不良の整理待ちは未整理のまま）**。**モデルは実在の肖像画（kako-jun 決定 2026-10-22「実在の肖像画がモデルだ」）。「実在の人物・氏名を使わない」系の方針（21 行・53 行・93〜94 行）の決定済みの例外**で、方針そのものは変えない。理由の読み（kako-jun 未確認）: 16 世紀の歴史上の人物で肖像画は古典の図像であり、現存の人物・事件・団体を指さない。名前はもじり。候補はセザール・ド・ノートルダム作とされる肖像（約1614年）を参照。肖像画自体の中央から上半身だけが飛び出し、人物は右を向く。縦長で上下左右対称の豪奢な金色ルネサンス額縁。絵の中に人物を残さず、人物は一人だけ。だいよげんの隕石は架空の天体現象とし、実在の災害・事件を想起させない。
- 背景は、実写の写真そのものに似せず、**デフォルメされたジオラマ**と分かる質感とサイズ感にする（2026-10-14 kako-jun。ファンタジアンの手法）。木は鉄道模型の木のように明らかに模型っぽくし、質感はプラスチックや土っぽく、粒子を荒くする。雪は、粉や綿で再現したような質感にする。**本当に身近な材料で作った手作りの模型に見える**ことが目標で、写真に見えてはいけない（2026-10-14 kako-jun。「身近にあるもので無理やり再現する」）。材料の例: 雪＝綿、木＝スポンジ・ドライフラワー・毛糸の塊、建物＝厚紙・段ボール・紙粘土、塀＝紙粘土や発泡スチロール、道路＝黒い画用紙や紙やすり、用水＝セロファンや透明レジン、電柱＝割り箸。接着剤のはみ出し、手で切った紙の縁、綿の繊維など、手作りの粗が見えること。ジオラマの土台の板や、まわりの部屋が見えていてよい（むしろ残す。AIくさくなくなるため。2026-10-14 kako-jun）。その上にアクスタを立てる見立てにして、縮尺の違和感を解消する。構図は、**奥行きを出さない**（2026-10-14 kako-jun。奥行きがあるとキャラの大きさの違和感が目立ち、不便になる。3Dにしない）。左右方向には広く、上下方向（奥行き）は浅くする。カメラは、**真上に近い見下ろし**ほどよい。
- **ジオラマ背景は「その場所のイメージ」であり、実際の地理・街並みの再現ではない**（2026-10-14 kako-jun。内灘の駅は砂浜にないし、香林坊もあの街並みではないが、「あくまでイメージだけ」という方針でよい）。ただし、鼓門のようなランドマークは、一目で分かる程度に実物へ寄せる。
- **香林坊・武蔵ヶ辻など市街地MAPの道路美術（kako-jun 2026-10-21）**: アスファルト部分は灰色の砂を敷いた工作で表現し、道路の白線は白い砂で描く。砂粒と手作りジオラマの質感を見せ、写真のアスファルト表現にしない。
- 背景はタイルを無限に継ぎ足さない。場所ごとに、全景・広い道路・狭い道・接続画を同じカメラ、光、反復物で一度に作る。視点は、真上に近い見下ろし（2026-10-14 変更。以前の「高めの斜め見下ろし（約45°）」は撤回）。フィールドは固定の一枚絵で、スクロールしない。絵の端で次の絵に切り替わる（2026-10-14）。

## 人物素材

- **4人とも日本人（東アジア）の顔立ち**にする。髪色は非現実でよいが、金髪の全面指定は白人の顔に寄るので、メッシュなど部分で入れる。
- **テーマ色は年齢とともに落ち着かせる**（2026-10-14 kako-jun）。ナム（ヒロイン）はピンクだけでなく青系もテーマ色で、大人になるほど青寄りの落ち着いた印象へ。**長いマフラーはナムの特徴**として、小学生から大人まで身につける。オトン（主人公）の赤も、落ち着いた赤や白へ移っていく。落ち着かせるのは服などの色で、**髪の色は派手なまま**。
- **大きな帽子はこのゲームの特徴**。幼稚園期のニット帽は4人とも大きめ。学生以上も大きな帽子をかぶってよい。デザインは年齢段階ごとに変える（幼稚園のニット帽と同じものにしない）（2026-10-14 kako-jun）。
- **決めポーズ**: 幼稚園児でもジョジョ立ちのような決めポーズをしてよい。同じキャラは大人になっても同じ決めポーズをする。
- 確定マスター: `assets/images/characters/Cxxx/masters/Cxxx-kindergarten.webp`。戦闘ポーズは `assets/images/characters/Cxxx/poses/Cxxx-{idle,ready,step,slash,hurt,down,cast,special,victory}.webp`（お遊戯会の園服版は `Cxxx-uniform-{pose}.webp`）（左向き・背景透過。元の 3x3 グリッドは保管しない。クロマキー背景で生成し、各コマの体にはみ出した刃・手足を付けて切り出す）。
- 採用方向は、実在人物を参照しない**実写寄りの生成キャラクター**。AI の定番アニメ顔、既存人物への類似、実在人物の肖像は避ける。
- 鉛筆線と透明水彩による非テンプレ絵は比較用に試したが、採用方向ではない。
- まず同一人物性を固定するマスター三面図を作り、決定後にポーズ一式をタイル状に生成する。
- 幼稚園期は、茶系の園服と、積雪時の子供用スノーボードウェアを両方作る。水色のスモックは採用しない。**お遊戯会の劇（冒頭の戦闘）は園服**で戦う。
- 小学生から上の学生期は**制服**を着る（北陸は小学生も制服）。小学生は男女とも**ブレザー**（女子はスカート）。中学から上は、男子（オトン・シャー）が**ブレザー**、女子（ナム・ペー子）が**セーラー服**（2026-10-14 kako-jun 決定。小学校にセーラー服はない）。一般的なデザインそのままにせず、**ジョジョのような変形学生服**も許される自由な時代として、各人が自分流に着崩し・改造する（案は生成で数種並べて選ぶ）。スカートの下にスパッツ・レギンスなどのズボンは履かせない。防寒着と、祭り用の浴衣差分も用意する。
- 壮年編の主人公は、車椅子のまま雪よけの羽織・防寒長着をまとい、子供たちを率いる非常に強い親の姿にする。
- 事故後の主人公は、戦闘もフィールドも**車椅子のまま**（想像の層でも立たせない。2026-10-14 kako-jun）。戦闘ポーズ・歩き（移動）も車椅子で作る。
- 事故後の主人公（オトン／ナム）の車椅子姿では、**脚の切断面は見せない**。膝掛けやコートで太ももから膝を覆う（2026-10-14 kako-jun）。
- 親世代は、子供時代の視点では固有の顔をはっきり描かない。子供から見上げる**顔の見えない巨人**として、腰から下、手、背中、靴、冬のコート、足音、声で存在を示す。親を目立たせず、視点の中心は四人の子供に置く。

- 配偶者の死後、相手が得たアビリティは主人公へ全て統合する。これは能力を奪う表現ではなく、二人で生きた時間が主人公の戦いに残る表現。

- 味方の武器は**刀に統一**する。日本刀は第三の装備品にはしない。スマホの能動アプリが生む、実体とも想像とも読める「想像の刃」として現れる。ヨーヨーなど他の日用品武器には広げない。銃は敵側の恐怖の像であり、味方の装備にしない。

## 召喚獣の場所調べ（2026-10-14、画像生成前の下調べ）

## #74 体内の最新空間・色の契約

体内は医学的な身体の再現でなく、現実離れした幼稚園児の想像する架空人体の抽象的概念。肌色寄りでよく、血や写実的な臓器・内壁を描かず、グロくしない。胴体は縦2MAPの上半身/下半身、手各2MAP・足各3MAPの縦通路ボリューム。頭は上、手は斜め上、足は斜め下。脳は迷路状通路、心臓・肺は単純な分岐室。背景共通の手作りジオラマに合わせ、5 mm foamboardの土台と見えるcorrugated cardboard断面、指跡・爪楊枝の跡を残したpaper clayの丸い地形を使う。肌色・薄桃・クリーム色のmatte poster paintで着色し、赤い折り紙を切った形を血痕に見えない明確な工作アクセントとして置く。毛糸は通路の縁や造形の継ぎ目に用い、雪の綿は使わない。白いPVA接着剤とmasking tapeで固定し、紙端・接着・塗りの手作り感を残す。旧『紙粘土・セロファンだけ』『口から手足が直結』という解釈を新規生成の固定根拠にしない（材料決定は2026-10-21 kako-junとの相談）。
