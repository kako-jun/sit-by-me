# BGMスロット表（FF5 全曲目を場面名に抽象化して作り直した版）

**状態: 案。スロット構成・長さ・兼用は決定ではない。** 物語上の決定は story.md・decisions.md・systems.md・art-direction.md が正本。ここで決まっていないことは「未決」と書く。新しい物語上の決定はここでは作らない。

## 0. 前提（置き換え済みの決定）

- **音源の使い方（決定）**: 新世界の録音から**切り出したフレーズ（10〜30秒）を Suno に読ませ**、**悲しい／楽しい／緊張・英雄**で系統分けして曲を作る。プログレ寄りのスタイル指定は現行（decisions.md・systems.md・bgm-suno-trial.md）。置き換え済みなのは、54スロット案（54→26に削減した旧スロット表。2.2 参照）の曲数だけ。足りない場面はアレンジ（編曲違い）で水増しするのが現行方針。
- メインテーマ（Largo 主題）は「遠き山に日は落ちて」の旋律（Dvořák 新世界より第2楽章）。人生の段階ごとに楽器を変える（systems.md「音」）。
- 曲数は FF5 並みよりさらに絞る。**26スロット・実曲は約20本**（kako-jun 指示。54スロット案から削減。ボス戦曲は存在しない）。街は4系統に分け、被災前後や時期違いは編曲違いにする。
- 未決: 旋律を誰がどう作るか、楽器の具体的な並び、ループ処理、SE の方向、権利確認（録音の権利は docs/bgm-sources-research.md、Suno 出力と既存曲の類似確認は別）。
- 本書が扱うのは**曲名と曲順（事実）だけ**。他作品の旋律・歌詞は扱わない。

冒頭の劇戦闘（中断あり）、地震（予兆・避難）、負けイベント戦、車椅子になる喪失、約束と回収、電車、雪（厳冬）、体内編、病院、時間制限の脱出、凍てついた海外、四人それぞれのテーマ（FF5 は仲間テーマ1本＋ヒロイン1本）、二周目（世代交代・巨人戦・上京の ED）。


## 4. 凡例

- **系統**（Suno 入力に使うフレーズの系統）: 悲=悲しい／楽=楽しい／緊=緊張・英雄。**日常・静かな場面は、場面の気分に近い方の系統に寄せる**（日常→楽、静か・喪失→悲、不穏→緊）。フレーズは新世界の録音から切り出した 10〜30秒（録音の選定は bgm-sources-research.md）。
- **Largo**: ◎=主役／○=一部に引用／—=使わない／未=未決。Largo は楽章2のフレーズを読ませる意味。
- 長さ: ループ曲は1周の目安。J=短いジングル。
- 兼用: 他スロットと同じ曲（またはその編曲違い）で済ませる先。旧ID は第2.2節の履歴を参照。

## 6. 集計と実曲数の考え方

スロット数: S=5、B=3、T=4、V=2、D=2、P=4、E=4、X=2、計 **26**（回想アレンジ PR01〜PR04 の派生4スロットは別カウントで、これに含めない）。ジングル（S02〜S05）は短いのでスロットには数えるが、実曲数には数えない（BGM として扱う。kako-jun 2026-10-16）。

実曲（Suno 生成）の見込み: **約20本**。S01、B01、B02、B03、T01〜T04、V01、V02、D01、D02、P02〜P04、E01〜E04、X02 が独立曲（計20）。
- P01 は S01 の編曲違い、X01 は S01 の編曲違い。
- 回想アレンジ（PR01〜PR04）は元テーマの編曲違いで、実曲数に数えない（別カウント）。
- 被災前後・時期違い・段階違いなどの編曲違いは、同じ曲のテイクとして数える。

## 7. Suno 入力の運用メモ（案）

- 悲しい／楽しい／緊張・英雄の3系統ごとに、新世界の録音から切り出した10〜30秒のフレーズを用意（各系統3〜5フレーズ）。Largo 主題を使うスロットは第2楽章、系統の違うスロットは他楽章の音色・動機を使う案（旧「他楽章の配当案」は第1・3・4楽章を悲／楽／緊に割り当てる想定）。
- 1スロットにつき複数テイクを生成し、採用は人間が選ぶ。録音の権利確認（bgm-sources-research.md）と、Suno 出力が既存曲に似ないかの確認は別途必要。
