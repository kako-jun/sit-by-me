# MAP位置関係図

- [overview.svg](./overview.svg): 北上固定のエリア間位置関係。
- [atlas.svg](./atlas.svg): 全104 MAPをエリア枠内で示す接続アトラス。

丸はMAP、実線は必須主路、茶破線はドア・乗車・ワープ・飛行機遷移、灰破線は主路と独立した任意枝を表す。画像生成・マスク実装で使う正確な出入口名は、図ではなく [`../map-topology.md`](../map-topology.md) の「MAP相互接続台帳 v2」を正本とする。

この図は **現行台帳の暫定可視化** である。特に後半（体内 `F19–F26`、海外 `F27–F40`、兼六園・金沢城 `F41–F60`）は、個別MAPの主路・任意枝・戦闘域・マスク契約を詰めるたびに、同じ正本から再出力して更新する。図そのものを接続の決定根拠にしてはならない。
