# Sit by Me — 企画の概要

実写の風景と実写の物が敵になる、現実ファンタジーのサイドビュー RPG。幼稚園の劇から始まり、人生を体感する成長物語。車椅子の主人公と、隣に座る人の物語。

## 一枚でわかる企画

- **題名**: Sit by Me（私の隣に座って）。車椅子の人の隣に座る、という動作で成り立つ。アクスタは「立つ板」で、そこに座った人が載る。
- **見た目**: 実写の背景の上に、敵も味方もアクリルスタンド風のスプライトを立てる。車などの物は実写の切り抜き、人物は生成のイラスト調。
- **主人公**: 性別をプレイヤーが選ぶ。必ず車椅子の側。相手は立てる側の異性の幼馴染。
- **物語**: 幼稚園の劇（段ボールのドラゴンと戦う）で始まり、劇のあとの水難事故で主人公が車椅子になる。友達の闇落ち（貧困、トクリュウの受け子、少年院）と奪回を軸に、少年編、青年編を経て、冒頭の劇の再来として本物の「竜」に立ち向かう。
- **主題**: 謝罪にも脅迫にも見えないほどの愛。同情と愛の違い。他の選択肢があった上で選ぶ愛。
- **戦闘**: サイドビュー、ATB、FF5 風の青いウィンドウ、ダメージ数字のポップアップ。武器は日用品、必殺技は武器に紐づく。
- **ジョブ**: 現実の転職（フィールドジョブ、主にパッシブ）と戦闘の役割（戦闘ジョブ、アクティブ）の二軸の合成。
- **FF の要素**: 勇者ヨシヒコのように、現実にあるものへ言い替えて入れる。

- エンジンの要件は name-name の Issue（systems.md の表を参照）。
