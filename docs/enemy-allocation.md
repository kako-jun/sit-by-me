# 敵の割り当て案（既存の敵 × マップ）と足りない部分

作成: 2026-10-15（kako-jun 指示「いまの敵を各マップにそれらしく割り振り、足りない部分を見つけて」）。

**割り当ての正本は `docs/dungeon-enemies.md`（kako-jun の一任による決定 2026-10-15。覆してよい）。1つの敵は原則1つのダンジョンだけ。本書 §1 の各地区表は、同書の採用案（重複解消後）に整合させた。§2.1 の不足の数と中ボス数の一覧は、この見直しの前の数え方のまま（最新の不足は同書 §4）。**

- 割り当ては `docs/dungeon-enemies.md` の採用案に従う。`docs/monsters.md` の「出る場所」へも反映済み（台帳の運用ルール: 記録に無いことは決めない）。
- 対象: 台帳の生成済み・仕様のみの敵（M101〜M151、M201〜M205）、物語の敵・召喚獣。マップは `docs/map-topology.md`（既存の絵と計画中の絵）。
- **雑魚戦の難度は高め**（kako-jun 2026-10-15。FF13 参照）。雑魚にも行動パターン・弱点・反撃・群の組み合わせの個性を持たせ、単調な消化にしない。種類数の目標（地区ごとの雑魚の数）は、この方針でも変わらない（再利用で補う場合も、群の組み方で戦い方を変える）。
- 方針: (1) **その場所にいて怖い物**（art-direction の「敵は明らかに怖い物だけ」）を、場所の性格・時期に合わせる。(2) 1地区に**6〜12種**を置き、1枚ごとに**3〜5種**から群を組む。(3) 時代が進むほど強く・大型に。(4) 同じ敵を別のダンジョンで再利用しない（原則1敵1ダンジョン。例外は兼六園の全敵再登場など。同じダンジョン内の別マップでの再利用はよい）。(5) 属性の魔法（火=ひあそび・水=ずぶぬれ・氷=とうしょう・風=ざくざく・土=どろだらけ・雷=かんでん）の**ラーニング元**になる敵が、各属性に最低1種要る。

### 2.2 属性の穴

**基準（kako-jun 2026-10-15）: ラーニングできる対象が1つあるだけで充分。そこでラーニングしないのはプレイヤーの責任で、0でない限りは救済と言える（FF も同じバランス）。** したがって、穴＝**0種**だけ。1種でもあれば「足りる」とし、「少ない」は問題にしない。
