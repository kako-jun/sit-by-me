# 敵の割り当て案（既存の敵 × マップ）と足りない部分

作成: 2026-10-15（kako-jun 指示「いまの敵を各マップにそれらしく割り振り、足りない部分を見つけて」）。

- **これは割り当ての案**。`docs/monsters.md` の「出る場所」は、kako-jun が採用するまで変えない（台帳の運用ルール: 記録に無いことは決めない）。採用された分だけ台帳へ反映する。
- 対象: 台帳の生成済み・仕様のみの敵（M101〜M151、M201〜M205）、物語の敵・召喚獣。マップは `docs/map-topology.md`（既存の絵と計画中の絵）。
- 方針: (1) **その場所にいて怖い物**（art-direction の「敵は明らかに怖い物だけ」）を、場所の性格・時期に合わせる。(2) 1地区に**6〜12種**を置き、1枚ごとに**3〜5種**から群を組む。(3) 時代が進むほど強く・大型に。(4) 同じ敵を別の地区で再利用してよい（種類数＝新規の絵の数ではない）。(5) 属性の魔法（火=ひあそび・水=ずぶぬれ・氷=とうしょう・風=ざくざく・土=どろだらけ・雷=かんでん）の**ラーニング元**になる敵が、各属性に最低1種要る。

### 2.4 サイズ区分の穴

- 1x1 が多く、**2x1・1x2 は11体、2x2 は 0 体**（ボスは大型だが未生成が多い）。方針「ボスはすべて大型」「敵は FF 同様に大小」を満たすには、**中型（2x2 の雑魚・中ボス）の素材**が要る。
- 既存の大型候補: ロードローラー（大型扱い）、大型ドリル、段ボールのドラゴン（M001）。**ドラゴン以外の 2x2 の通常敵が無い**。

### 2.6 時期・印象のかぶり

- **氷柱・凍った水たまり・夜の森の枝・スズメバチは出番が多すぎる**（寺町・香林坊・卯辰山・能登・兼六園）。地区ごとに「主役の敵」を決め、再利用は脇役にとどめる。
- **水辺の敵（ウニ・ゴンズイ・フグ・タコ）は、内灘・能登・水族館・川の4か所で重なる**。内灘は海岸、能登は漁港、水族館は水槽、川はゴンズイだけ、のように分ける。
- **都市系（バイク・自転車・ロードローラー）は寺町・香林坊・内灘・海外で重なる**。地区の道の性格（広い道路・路地・駅前）で出す種類を分ける。
