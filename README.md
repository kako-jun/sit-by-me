# Sit by Me

実写の風景と実写の物が敵になる、現実ファンタジーのサイドビュー RPG。幼稚園の劇から始まり、人生を体感する成長物語。車椅子の主人公と、隣に座る人の物語。

すべての人物と物を、実写背景の上に立つアクリルスタンド風に統一する。エンジンは [name-name](https://github.com/kako-jun/name-name)。
